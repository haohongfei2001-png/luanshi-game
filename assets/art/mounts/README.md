# 河关 · 战马与轻车

这是《乱世》专用的原创网格、动画变形与绘制纹理，马的肩、胸、颈、颊、臀和四肢由同一张连续表皮连接，按解剖截面烘焙后交给 Godot 驱动。毛色随马匹稳定分配，站立时鼻端会轻动，尾部有独立的摆动。作者源文件是 `tools/art/bake_mounts.mjs`；Node 自带的标准库即可重烘，`node tools/art/bake_mounts.mjs --check` 会对提交的三个美术文件逐字节复核。网格遵循仓库的分发条款。

Godot 会把 `mounts.gltf` 与相邻的 `mounts.bin`、`mount-atlas.png` 导入为一个资源库。正式战场从 `mount_art.gd` 取得一批一面的 Mesh，所有实例共享 256×256 原色图集；着色器分别处理马毛、角质、皮、布、木与金属的粗糙度。场景节点表达模型目录，不需实例化一套节点给每一匹马。

| 网格 | 三角面 | 内容 |
|---|---:|---|
| SaddleClose | 7,038 | 带衔铁、双耳、眼睑/鼻孔、鞍面、鞍毯、双镫、缰绳的坐骑 |
| SaddleRank | 1,608 | 同体态、步态与四肢关节，保留远看清楚的鞍毯轮廓 |
| DraughtClose | 9,524 | 胸带、牵引带和辕杆相连，轻车轮辋、辐条、轴毂、底架及车板 |
| DraughtRank | 2,840 | 同一马车轮距、车座和牵引关系 |

单位为米，马鼻朝本地 +Z。鞍心 `(0, 1.44, -0.04)`；衔铁 `(±0.105, 1.56, 1.15)`；骑乘缰绳手位 `(±0.17, 1.594, 0.24)`；车站位 `(0, 0.91, -1.83)`；轮轴 `(0, 0.55, -1.83)`。UV0 定位图集，UV2.x 标记四条腿、枕/颈、尾、轮；UV2.y 使头颈与缰绳由衔铁到手自然衰减。视觉按实际行进距离插值，没有给每匹马增加物理体或独立动画树。

马头、眼睑和鼻翼按表皮距离场定位。远档保留了侧面眼窝、鼻孔、上唇与从颈侧落下的鬃毛。毛色的明暗和四肢末端颜色跟随绑定坐标；鞍座、衔铁与车架的尺寸沿用原型。起步、快步与小跑使用实际行程驱动蹄子的承重、提步与落蹄。

胸廓、肩胛、后腰和臀肌在近远两档都按连续体表生成。行走时肩胛到前肢、臀肌到后肢采用渐变权重；负重脚仍按实际行程落地。鞍垫保留独立织物，马毛的亮面随实际光线顺着体表转折。
