# 河关军容资产

河关正式战役在 Godot 导入 `river_company.glb`，用同一套手部握点、衣甲材质和骨骼姿势装配近景与中景士兵。主角、队正、重装兵、弓弩手和普通步兵共用尺度与绑定。衣片、札甲孔绳、头巾、面部与装备由本仓库的模型和绘制源文件生成。作者为《乱世》项目本次开发，无外部模型、扫描、字库或贴图。分发遵循仓库现有许可。

在安装 Pillow 的 Python 3 环境中执行 `python3 tools/art/bake_river_company.py` 可重建模型与三个 PNG。材质册以四乘四方格保存十六种表面。姿势册逐帧存储骨骼旋转与位移。手掌、兵器、支撑手、弓弦共用握点，动作阶段由正式战斗状态驱动。
