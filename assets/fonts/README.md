# Noto Sans SC Regular

The source bootstrap downloads the unmodified Simplified Chinese OpenType face from the Noto CJK Sans 2.004 release. The upstream font retains its embedded copyright and naming records. The package includes the SIL Open Font License in its third-party notices and game resources. The downloaded asset is used offline after preparation.
