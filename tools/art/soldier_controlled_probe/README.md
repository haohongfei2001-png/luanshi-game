# Complete controlled soldier visual oracle, NOT shipping or crowd architecture

This single-actor diagnostic evaluates the unchanged mature source rig and the
new editable whole actor, then plays the evaluated vertex cache in actual Godot.
It does not instantiate471 CPU bones for each ordinary soldier. Source308 Guardian
body/control bones and163 MH head-module bones stay in the authoritative editable
Blender master. The hidden65-bone UAL donor is an authoring reference only.

`rebuild.sh` locks published MH builder b778bc0f and stable carrier baseline
53c08673. Later projected shoulder trials are rejected, so they are explicitly
NOT selected for this motion probe. Source fetchers verify exact reviewed member
hashes/licenses. All original source files remain unmodified. Intermediate
rejected kit is removed completely, not silently revived as final art.
