# 《乱世》唐末至清代战争史：战役、兵种、武器、器械与可复用玩法研究 v1.0

**2026-11-12｜正式研发参考｜Owner 指定研究范围：唐末—清朝（含清末）**
**性质：研究筛选与游戏机制转译，不是历史剧情定稿、历史事件必然重演、已完成代码或要求立刻把所有项目塞进首版。**
**权威**：`docs/PRODUCT_DECISIONS.md §1I/§1J`；`docs/BATTLEFIELD_VARIETY_AND_FORCE_ROLES_20261112.md`；`docs/CENTURY_WAR_ERA_CAMPAIGN_V0_1.md`；`docs/ACCEPTANCE_MATRIX.md §7F-C/7F-D`。

## 1. 研究方法与原则

**用户真正要的是：充分考察唐末至清朝真实发生过的不同类型战役，发现适合《乱世》的军事玩法、兵种、武器、装备、器械和地图环境，再转化成有因果、有互动、有反制的系统。** 不是必须还原每个年号、人名、胜负，也不是把历史变成数十个静态剧情关卡。

- **三层分离**：A「史实参考」=史料/研究支持的战役、军备、制度与地理；B「玩法转译」=为游戏设计的可选机制、胜负和动态变体；C「架空扩展」=用户允许的个人武力成长、叫阵小将等经过戏剧化的设计，不宣称真实历史中的常态。
- **历史可信度分类**：标为「案例」表示确有对应的战争/战役；「时代原型」表示同一时期反复出现的战争模式而非单次名战；「细节待核」表示尚不能据现有检索材料作准确战术/人数/装备细节断言。禁止把戏曲、演义、影视中单挑或神兵设定直接当历史定论。
- **玩家不支配历史**：相同地形、双方军事能力、物资/水/粮道、指挥和动态世界事件能够产生多种结果。斩将或死亡比例绝不直接决定战争胜负；战术目标和战略后果分开。
- **研发次序独立于史实年代**：初版仍先磨好一张精良战场、512v512 真正交战、敌我强将与九种武器、M5 60 FPS 目标。研究库中的不同战场机制可按高复用价值分期加入。尽量共用军阵、地形、侦察、任务/补给、工程器械、指挥与胜负判定。
- **压缩千年为单生涯时**：游戏技术/政治压力经过架空时间加速但要连续、有产业与扩散前提；不强迫沿真实朝代顺序过关。现实历史用作「可能发生的军事局势」而非强制脚本。

**关键技术判断**：宋代已存在多种火药军器，12—13世纪火药开始广泛进入围城、陆战及水战，13世纪出现较早真正的枪炮。**“宋元完全无火器、到清末才解锁火炮”是错误设计**。火枪（火矛）、火药弹、早期火铳、近代鸟铳/火炮应有不同能力/前置条件；抛石器械的“炮”一词**不一定指火药炮**。[S2]

## 3. 有选择地加入兵种、装备、攻防器械，而非铺满九百年的清单

### 3.1 战斗单位的可复用核心类型

| 核心类型 | 常用变体与兵器 | 真正的区别 | 适用/时代条件 |
| --- | --- | --- | --- |
| 前排盾/刀剑步兵 | 轻盾、重盾、长刀/单刀/剑、甲胄 | 正面挡射、护盾覆盖、短距离切入、打断和近身强攻 | 多个时代，但式样/材料持续变 |
| 长兵器队列 | 枪矛、长柄刀、棍/重兵器、拒马工事 | 对冲锋与骑兵的拒止、列阵间距、被侧击/贴身后的弱点 | 冷兵器时期核心，火器普及后仍可存在 |
| 远程队伍 | 步弓、骑弓、强弩、连弩（具体型号须考证）、火绳枪/鸟铳 | 射程、覆盖、弹药补给、装填、掩护、抛射和射界 | 弓弩先，火器按技术能力逐步加入 |
| 骑兵 | 侦骑/轻骑、具甲冲击骑兵、弓骑、骑枪/刀骑 | 追击、诱敌、侧翼、冲击、马匹和马料、崎岖/林地损失 | 多时代；草原/山地/南方生态差异 |
| 精锐与军官 | 老兵/亲兵、先锋、叫阵小将、营官、主将/帅 | **武力和统率分开**；精锐/小将可强于普通兵但不必有高职位，领兵者不必最强战士 | 以个人训练和部队制度决定，叫阵属戏剧化可选 |
| 工兵与辎重 | 担架/救护、传令兵、斥候、筑壕/架桥、冲车/云梯、运输车马 | 修路/筑营/攀城/攻门/运粮与伤员撤出；是战斗资源不是背景人数 | 从开局即可逐步实现 |
| 早期火药队伍 | 火矛/火枪、火药弹/烟火/燃烧物、早期火铳 | 短距离/射速/失误/天气影响，技术与工业较不成熟 | 宋金元阶段逐渐发展，不当现代枪 |
| 明清火器/炮兵 | 火铳、鸟铳/火绳枪、佛郎机炮、城防重炮、早期野炮 | 装填、炮位、炮弹/火药、训练、射界、后坐、炮组与运输 | 明清中前期已存在，不用等清末 |
| 近代陆军与海军 | 新式火炮/步枪、炮兵/工兵、战船舰炮、后期蒸汽/铁甲舰 | 工业维护、海况、现代火力和指挥链代差 | 晚期技术/船厂/财政/培训链充分才允许 |
| 舟船/舰队 | 江河渡船、运输粮船、较小战舟、大型楼船、远洋帆船、炮船、蒸汽舰 | 水深/吃水、速度/船形、载员、风/水流、接舷/舷侧火力/炮口 | 自早期河战到近代海战跨时代升级 |

**重要边界**：
1. “小将一人向阵前叫阵、双方主将单挑”可以作为游戏中的可选戏剧化战场事件，不能作为普遍有充分史料证明的标准战争规则，不能迫使敌我都停止交战观战。
2. **晚唐“战车”不宜等同先秦车兵**。用户要战车玩法可采用架空特种车、辎重防御车/车营等适合地域与时代的变形，不把唐末军队标准编制写成先秦双轮战车冲锋。
3. “铁浮屠”“拐子马”等后世通俗说法及其具体战术形态存史学争议；若引用，需单独查证而非直接生成具有神奇属性的超人骑兵。
4. 战斗力、勇武与统帅官阶不是同一数值。武器装备受库存、战损、补给与地区材料限制；同一时代允许不同政治集团有不同步骑与火器普及率。
5. **火炮不能一概归到清末**：区分（a）冷兵器投石“炮”（抛石器械）、（b）宋金元早期火药军器/早期金属火铳、（c）明清早期枪炮和野/城炮、（d）晚清工业化舰炮/近代火炮。技术谱系不是四个突然切换的关卡。

### 3.2 器械/攻防场景可在同一系统中复用

- 工事/防御：护城河、城门/门闸、城垛、箭楼、碉楼、山口栅栏、寨墙、深壕、浮桥、船桥、道路障碍、拒马与野战营盘。
- 攻城/阵地器械：云梯、冲车、搭桥与工兵、抛石机/配重投石机、火药弹、可受损攻城车、野战炮/守城炮（时代条件严格区分）。
- 水战/海战：渡河舟船、粮船、江河战舟、楼船、小型快船、海船、较晚的有炮帆船/近代舰队；浅滩、风/水位、暗礁、岸炮、港口/船坞。
- 战役级支撑：粮仓、水源/井/河口、马场与马料、道路/驿站、河桥、码头、山林、斥候/哨卡、夜间营火、天气与疾病、守军/后备兵营。
- 高威力手段均须有反制：火攻需要可燃物/风和燃料，炮击受射界/装填与弹药限制，伏击受侦察与遮蔽约束，长期围困受后勤与援兵影响。

## 4. 为什么这比“复刻二十场战役”更重要：共用 11 套战争变量

每个真实战例转译成可组合的**战役条件**：
1. 地形骨架：平原/高地/山口/林地/沼泽/桥河/港海/城寨。
2. 可争夺地点：关隘、道路交汇、粮仓、营地、水源、城门、码头、多个据点。
3. 双方不对称目标：突围、截运、争点、守时、围困、护送、救援、夺城、海上封锁。
4. 战场侦察：白昼/夜间、视野/烟雾、巡逻/斥候、信使/鼓角的可获知范围。
5. 军制与军官：叫阵小将/先锋/亲卫/战场主将/后方统帅，军令与继任/救护。
6. 军阵兵种与装备：同一个武器大类在不同年代有训练/射程/防具/装填与成本变化。
7. 战役时钟：动员/部署/行军/接敌/围攻/援军抵达/物资耗尽等耗时事件。
8. 补给与工程：粮水/马料、运输车辆/舟船、攻防工事、城墙、火势与火器弹药。
9. 人性与组织：士气、训练、关系、失令/违抗、残军重整/背叛/撤退。
10. 环境与季节：河流深浅、山路通达、风雨、泥泞、寒冷、暑疫、营地卫生。
11. 军事结局：局部胜、战略败、主力得存、俘降、停战、延期、撤围/转攻另一城，不以斩首为快捷胜利。

**强烈建议架构**：`HistoricalBattleReference`（研究记录，不在普通玩法必显示） → `ScenarioTemplate`（地形、双方军力/编制、科技/装备条件、任务/部署与物流） → `WorldBattleInstance`（有实际起源、固定世界坐标/资源/实时状态与自主敌方 AI） → `BattleOutcome`（客观损失、目标与战略后果）。此模型能在一个地图上演示多种战争，也可渐进扩到不同城池/海面/全国战场。

## 5. 分阶段投入与长期机会成本

**P0：既有千人战场真实战斗与性能不可退化。** 先收口 PR #17/18 的 CI、双边将领、九武器、实装关门/坡/桥/多点/战损和 M5 性能验证；正式剧情仍空白。

**P1：最高投入产出比的战史元素（优先做）**
- 平原骑步对抗/先锋与精锐；
- 山口/桥隘、两城联动/援军；
- 粮道与水源、撤退/突围；
- 夜间侦察与营地偷袭、伏击；
- 城门/攻城器械及多点阵地；
- 不同战场环境通过同一可复用 ScenarioTemplate 配置。
这些系统可重用大量历史战役，但不需要数十张新地图。

**P2：更高内容与工程成本**
- 更丰富的山地/林地/丛林、暑疫与复杂天候；
- 河道/渡口/浮桥/船队，水战与围城同时存在；
- 火攻、燃烧船、攻防地形与真实烟雾/可见性；
- 各种可部署工程、阵型、围城与不同城市布局。
可复用上述系统，慢慢提高每种环境的画面品质和 AI。

**P3：随科技/国力/时代开启**
- 宋元火药军器、明清火器/炮兵与混合阵型；
- 城防炮台和舰炮、港口/海上运输、远洋舰队；
- 近代炮舰、工业化军工、蒸汽/铁甲舰海战及跨海远征；
- 不能用更大的炮数值代替射界/训练/装填/资源/工业与航路。

上述 P0–P3 是**工程投入优先级**，不等于历史按 900 年顺序跳年份。技术时代与独立世界的速度须结合 Owner 的单主角历史压缩愿景，至少有一条正常寿命合法路径可以遇到近代海权危机。

## 6. 持续研究与审核机制（Codex 后续维护）

- 任何新增武器/器械应记录：**史实最早/典型使用年代范围、地域与势力、是否普遍装备、证据链接、争议、3D 外观参考、兵种定位、真实成本和该时代可否使用**。没有来源不能以“历史上就是这样”写入官方百科。
- 先参考博物馆实物/馆藏图、学术研究与正式战史；以画面概念图、电视剧、战棋/游戏或演义作为**审美参考**时需独立标注，不自动当史实。馆藏图片/网页不一定可直接作为游戏贴图，素材版权和许可证另行核查。
- 对每个新战役类型至少提交：一场可运行的真实战争、一种不以全歼/斩将判胜的目标、固定种子下改变兵种/地形/补给的因果对照；与 512v512 战场/旧存档同账，摄像机切换后状态连续。
- 本表为**第一轮 20+ 个战例/战役群的系统化筛选**，不是“研究已穷尽唐末—清末所有战役”。后续可以有针对性扩充，例如独立研究宋夏边堡、金元骑兵细节、明代车营、清代海防、火器和舟船图谱，而不是无差别上千次搜索。
- 不把真实战争暴行当作炫耀性奖励；保留用户已锁定的困难公平与人物命运系统。军事地形/后勤/动作与水战的设计仍需适合现实游戏性能和合法素材来源。
