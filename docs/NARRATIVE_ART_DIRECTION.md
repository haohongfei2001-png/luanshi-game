# 《乱世》叙事与视觉执行规范 v1.0 — Pro 设计，Dot 自主制作
依据 PRODUCT_DECISIONS.md 中用户已锁定的：**架空古代中国、克制写实、三支柱均等、困难但公平、有限生命、有限情报**。
本文是让 Dot 可自主产出故事、美术、镜头、UI 的执行准则；示例名与人物表不是新的用户强制决策，具体创作允许演化，但不可破坏规则。

## A. 作者表达：讲“人有限，天下未定”

核心主题不是强迫玩家失败，而是**战争胜负、政治秩序、亲友命运、身体寿命和情报完整度常常无法同时被优化**。一个良好的胜利可以在局部实现，但未必能解决远方的灾祸；玩家最终可能成为英雄、失意者、实用主义的统治者、退居一隅的守将，或早早战死。

戏剧张力来自玩家确实可以选择：保存士兵还是增援，征粮还是救灾，守军令还是救同袍，撤退还是赌博式夜袭。**每种选择能改变真实数据**，不得只把不同对话导向同一预设“坏结局”。

## A2. 所有者确认的“不可改变／可改变”叙事边界（2026-11-08）

**本节对后续所有剧情创作有约束力。**

### 不可被普通选择抹去的结构历史
这是东汉末—魏晋风格物质文化的虚构乱世，社会已经存在朝廷/地方军权矛盾、边境战争、人口与物资紧张；外部势力有自己的战争目标。**玩家不参战、躲到某座城、辞官或隐居，也不能让这些背景冲突消失**。战争消息、征粮、流民、城池归属和将领生死仍在世界持续演化。

### 可以改变的具体历史
一场围城能否坚持、援军是否赶到、守将是否降、城池何时陷落、哪支军队幸存、谁因误判而死、玩家能否获得军权，全部可在规则内改变。故事不是“主角救援成功也强迫安平失陷”；背景不可避免的战争 ≠ 每一场战役都必须有固定胜者。

### 作者设计的关键节点、动态发生的普通选择
| 类型 | 叙事处理 | 对世界的影响 |
| --- | --- | --- |
| 历史锚点：战乱和政治矛盾 | 作者确立世界初始状况、相关势力诉求、正在酝酿的战争 | 战争时代不会因主角不行动而消失，世界持续推进 |
| 日常选择：分粮、巡营、普通交战 | 通过世界规则、小对话和战报自动表达，不写海量重复式任务 | 通常只改局部库存、关系、士气、小队战果 |
| 关键剧情：解围、阵前倒戈、军权争夺、大规模战役 | 作者提供若干紧凑的重要人物/台词/变体，触发需世界条件成立 | 有实力、位置、军权、情报和时机的玩家才可能影响战略大势 |
| 结局/余波 | 用玩家视野可知的生平、军报、未决传闻交代 | 无论玩家是否统一、是否进取，世界仍有其后续 |

**避免重复**：不要用十场结构相同的刷怪、二十次强制等待、反复收同一军粮把游戏撑到既定小时数。战争可通过快进、战报、远方局势变化推动故事；把预算集中在少量真正改变人物/阵营/军队的节点上。

### 人生与政治自由的真实限制
允许玩家尝试辞官、叛逃、聚众、割据、称帝或退隐，但没有军队支持、合法性和物资基础时可以失败。人物有自主立场，玩家的选择不意味着支持者自动出现。**退隐是危险乱世中的另一种人生选择，不是隐身进入安全的“悠闲生活模拟器”**。

### 悲剧的尺度
主题是**个人生命的有限性与历史无法被一人完全掌控**。胜利与友情都可以真实发生，悲剧不是唯一被允许的结局。主角的宏观影响与其军职、经验、可支配资源和时机成比例，大部分普通选择不应不可思议地改写整个帝国。

## B. 架空历史的写作规则

推荐工作时代为“虚构王朝末期，生产力与军事技术大体借鉴东汉后期至魏晋，但不混同真实朝代”。国家工作名“晟”，敌国/割据势力、地理名称由 Dot 保持统一、建立世界地图词典。史实只提供战争补给、官制/军职、装备和人性方面的参照；具体历史人物、年份、事件不作为玩家必须照演的真结局。

世界背景的持久冲突：
1. 朝廷与边军互相依赖但互不完全信任；
2. 边境入侵、治安崩坏与地方征发使农业、人口与军备受损；
3. 重要将领在忠义、家人、军权、财富和存续之间有不同目标；
4. 普通居民会感受到征兵、灾荒、战事、迁移和换旗，而不是纯背景装饰。

不需要给每一座城制作一套完整社会模拟；把少量真实可追溯的人物和城市经济状态写扎实。

## C. 第一段剧情：北境安平救援（真实闭环，而非固定关卡）

### 初始可观察状态
- 主角：24 岁边军小校，自有可指挥士兵少量，装备与粮食不足。玩家能在营帐、仓库、简陋城门与战场之间切换。
- 平陵：玩家的驻地。离开后驻军减少，可能遭敌军骚扰；军需官应指出此风险。
- 安平：三日前发出求援；当前实际状态只在 WorldSim 存储，玩家初始并不知道。
- 河曲：道路/粮道要冲，可以改变行军时间、运输与围城补给。
- 敌方围城军：有实际兵力、将领、补给与可替换方案；不是“专门等玩家来送经验”的固定敌人。

### 五个主要人物原型
| 角色 | 公共信息 | 真实动机或矛盾 | 可以发生的变体 |
| --- | --- | --- | --- |
| 主角（边军小校） | 年轻、尚无很高军权 | 希望建功、保全同袍或尽职 | 成功、负伤、改任、战死、后续升迁 |
| 安平守将 | 受命坚守 | 维护军令与保存百姓之间的冲突 | 守、议降、突围、被俘、战死 |
| 平陵军需官 | 管仓与征发 | 不愿为了一个赌局耗尽本地守军的粮食 | 支持、阻止、隐瞒缺口、协助征粮 |
| 老兵同袍 | 善战且了解边民 | 重视身边人的生存，可能不认同冒险军令 | 战功成长、旧伤、救主、离去、被俘 |
| 敌方主将 | 外来军队最高执行者 | 既要完成上级命令又要避免断粮与内乱 | 强攻、撤围、议和、诱敌、等待援军 |

NPC 不能无条件绑定剧情：一旦真实战死或撤离，后续场景要切换到幸存者、信使、遗物、军报或空位，而不能凭空复活。

### 玩家可采用的策略（只有相关系统完成才开放）
1. 立即直援：到达快但军粮和侦察准备不足；安平可能尚在，也可能已陷落。
2. 先派斥候：改善信息，但消耗时间。
3. 从河曲截敌粮道：可能迫使敌方撤围，却给平陵留下更少驻军。
4. 征用民粮：增加本军补给，降低当地生活保障与民心；之后会影响生产。
5. 坚守平陵：保存本地，却可能失去安平及其重要人物。
6. 退避/谈判：可以以领地、俘虏或军纪代价换来士兵生存，不是自动失败。

事件不是固定“选项 → 结局”表；先修改世界状态，再让在场与离屏角色根据状态做行动。用剧本表达后果而不是替代因果。

### 至少四条可复现结果
- 救援及时：可以破围，但要结算战死、粮耗和人物关系；不无代价“完美胜利”。
- 救援迟到：安平已失陷；玩家应能发现前情并合理选择是否追击/退兵。
- 截粮成功：敌军先行撤围，玩家少打一场野战，但另一条战线可能产生空虚。
- 守将议降：如果根据真实伤亡、粮食、其主观情报认为守城无望，且其家人/百姓利益迫切，守将可能投降，守军中又可能发生反对或分裂。

必须能演示“只改变出发时间/斥候/运输等条件，得到不同结果”，而不是抽签刷结局。

## D. 长期叙事结构（主题阶段，不锁剧本）

1. **入伍与边关**：与具体士兵建立关系，武器、粮食、军令限制非常明显。
2. **军功与失去**：连续战役，主角能取得个人战功，发现救援与补给的代价，体验晋升或失势。
3. **分裂与乱世**：边军、朝廷、地方势力动机冲突；出现阵营选择、将领倒戈、军团战役和城池更迭。
4. **权力与老去**：玩家体力可能衰落，统御依赖下属；更多时候决定行军和资源优先级，而非亲自杀尽敌军。
5. **人生终章**：死亡按身体与局势实际发生，不指定年份/地点。收束成可知事实、传言、缺失信息与私人遗憾/成就。

玩家可以在任意阶段战死，不应被告知“必须统一才算通关”。若长寿、成功、提早归隐，同样可出现有意义的人生结局。Dot 在每个阶段至少创作一项同袍命运转折、一项资源/民生代价、一项政治/军令纠葛。若开发期短，优先深写三城而不是空洞扩城。

## E. 事件与对话的内容数据协议

每个事件推荐记录：
- id / trigger：在哪些真实 WorldSim 条件成立时进入可观察状态；
- participants：参加角色的 ID 和缺席/死亡替代；
- requires_knowledge：玩家/角色需要掌握哪些情报才可以看到对话；
- choices：仅列可执行的行动，给出提示但不暴露不存在的确定性；
- mutations：通过正规世界行动更新补给、关系、伤亡、城市归属、军令或消息；
- consequence：改变后的可知结果与可能推迟送达的消息；
- fallback：条件不成立时是否跳过/转为谣传/落空的军令。

对白要求具体、有身份差异，避免现代口吻和冗长设定讲解。玩家可以通过动作理解角色，比如军需官在粮仓前阻拦而不是只展示“民心 -15”的弹窗。

## F. 死亡/结局演出的规则

- 游戏停止该局继续操作，进入简洁的“生平”“已确认的局势”“未有定论”三个内容区；
- 生平包含年龄、军职、真实交战与可合理查证的重大行动、亲友关系和疾病/战死原因；
- 只披露玩家或生平记录能够获得的消息，像“二十年后该国灭亡”的全知预告**不可随意出现**；
- 尚未获证实的失踪/军队去向应以“不详”“有传闻”表达；
- 提供重新开局/人生节点/加载存档；重来时战略事件依种子和玩家行为复现。

## G. 美术规范：小但精致、粗粝、克制写实

### 视觉目标
斜俯视角色具可信人体比例，不做 Q 版大头、夸张发光铠甲、过度特效。小人的“精致”主要来自：
- **轮廓**：长枪、刀盾、弓、甲胄有清楚的特征；
- **层次**：粗布、补丁、系带、旧皮/札甲/布衣、朴素头巾或简易盔具；
- **群体差异**：同一军队不完全相同的装备、磨损与颜色；不能让军需不足的队伍凭空全员重甲；
- **动作反馈**：走路/冲刺/攻击/击退/挡格/溃逃/倒地有明确可读的动作节奏；
- **尺度**：拉远能看出方阵与队伍动向，拉近能看到装备差异；重大情绪靠镜头、立绘、音乐和文本表现。

### 服装与装备分层
| 身份 | 轮廓/材质 | 避免 |
| --- | --- | --- |
| 贫民/征募农夫 | 洗旧粗布、简单束带、草鞋或赤足、农具 | 人均整洁制服/名贵绸缎 |
| 富户/军需官 | 做工较好、层次丰富但不过分奢华 | 现代时装与高贵套装 |
| 普通步兵 | 简易枪刀、杂甲/旧甲、有时无甲或无武器 | 统一精致板甲/超自然雕纹 |
| 老兵/军官 | 更多实用装备、磨损、修补、抢来的盔具 | 只能通过金光特效辨等级 |
| 主角后期 | 经验与战利品使装备更可靠 | 随升级凭空出现神兵铠甲 |

不机械断言中国古代所有时代装备都简陋；架空世界需有一致的生产技术上限和身份差异。视觉参考的使用要记录来源；不得照搬商业游戏 IP 与素材。

### 场景与镜头
地面、城墙、营地、路网、山岭与河流首先传递战术信息。建筑布局要支持部队通行、守卫、攻城而非只做摄影背景。战场战斗视角应配合轻量阴影、适度雾尘与区域光照，不让视觉效果掩盖敌我与鼠标瞄准。

### 技术与资产预算
- 占位体 → 清晰低中模人体 → 简单骨骼/动画 → 装备模块/材质变体 → 重要立绘和有限镜头演出。
- 大量普通兵共享动画与材质，使用 LOD/实例化等手段减负。可视人数由压力测试决定。
- 仅使用能合法纳入公开仓库且未来可商用的原创/可明确许可素材；记录许可、来源和必要署名。无许可则先用程序化占位素材。
- 音频尽量服务战斗可读性：脚步、敲击、号角、哀嚎克制；不依赖夸张大片配乐。
- 可访问性：色盲友好的所属标识（形状/轮廓优于仅颜色）、清晰文本、可关屏幕震动、音量控制、按键提示/重绑。

## H. Dot 自主创作的边界

Dot 可自定虚构国号、地点、人名、对白、具体建筑与次要支线；可裁剪低价值内容，但不得改变用户确定的核心操作、克制写实、三支柱等权、困难公平、有限情报、人物寿命死亡与回档。需要在 GitHub 记录新增内容和资产许可。**所有普通创作问题由 Dot 自行完成，不请求用户逐项决定。**
