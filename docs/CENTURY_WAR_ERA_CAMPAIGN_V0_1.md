# 《乱世》压缩千年战争的单人生涯：时代压力与可变历史 v0.1
**2026-11-12 · Owner 新增长期世界愿景 / Pro 整理为实施规则**
**文档性质**：用户明确提出的“可以在一位主角的一生中，沿一条足够成功的道路经历多个历史战争原型”是正式产品目标；本文的具体数值、地名、历史映射及工程结构是 Pro 的可调建议，**不是用户亲自写出的不可修改剧本**。
本文件补充 PRODUCT_DECISIONS.md 的 LOCKED 规则；不取代 NARRATIVE_LIFE_ARC_V0_3.md 的十五岁军旅—人际—权谋—家庭人生主轴。具体核心人物、台词与戏剧场面仍由用户单独设计，Dot 不得擅自把长篇叙事写成正式定稿。

## 1. 新的体验目标：不是多玩几代，而是同一人有机会见证压缩千年

- **同一主角、同一世界、同一生涯**：从约15岁入伍、面对唐末式藩镇之乱起，在高生存率且足够成功的**可达路径**中，经历王朝覆灭/更替、群雄统一、三方北境强敌、失去半壁江山与海上末战/北伐复国、迁都和军权财政权衡、内乱与北方强敌并发、直到舰炮与外来条约战争式危机。
- **不是所有人都会到达末期**。主角在任何阶段都能早死、失势、被俘、当臣子、长期割据、偏安或沦为流亡者；此前每一阶段都应有可继续的人生和终局，不靠固定脚本保证一路胜利。
- **用户说的“允许玩家可以做到经历至少”必须通过可达性测试**：在一条非作弊的高水平成功路径中，主角确实能在自然衰老前遭遇上述各主要危机，不应因默认年代固定或强制一百年后才解锁而必然无缘见到后期。其他路径则无需全部经历。
- **历史压缩是刻意的架空规则**：它不是唐、宋、元、明、清历史真的在几十年内发生的事实。以“约一百年承载历史上近千年的军事政治变迁”作为世界愿景，但主角以十五岁出发且可能在七十余岁死亡，故成功路径应当可以在**约五十至六十余年的一生**里触及后期危机（准确门槛通过游戏测试调整），**不能强迫主角活到115岁，也不允许把玩家转接儿子继续游戏**。
- **战争时代与外部文明并不等待玩家**：技术、中央/地方权力、人口与外来势力在离屏持续演化。玩家是否进取不改变这种世界动能；他可能只看到其中一部分。

## 2. 历史事件是“压力原型”，不是准确复刻的固定剧情

下面用历史名称方便作者与开发者定位体验；正式游戏仍是**架空王朝与架空人物**，不能让真实朝代、历史人物与年代强行连续登场，也不得保证实际历史中的失败必然重演。

| 时代压力或玩家可遇到的情境 | 历史借鉴 / 代表性问题 | 可变后果（至少） |
| --- | --- | --- |
| E0 乱世少年与藩镇战争 | 唐末藩镇内战、中央军仍可能强大、朝廷衰弱与争功 | 主角入伍/转投藩镇；能守边也可能叛变；王朝可能灭亡、转型或勉强复兴 |
| E1 旧王朝灭亡与群雄统一 | 朱温篡唐、五代纷争、黄巢式民变与争夺天下 | 旧中央可能崩溃；主角能当臣子、割据者、革命者或统一者；旧朝也可能被成功维系 |
| E2 北方三强敌 | 宋式辽、西夏、金等相互制衡（各有自己的经济和政治） | 局部议和、割地、结盟、征伐、各个击破、未能应敌；不必每个敌人都依次一键刷出 |
| E3 半壁江山与末局 | 北方失土、偏安南方、崖山海战式最后决战与反攻统一 | 可暂退南方、海上保全残军、被攻灭、北伐成功或扭转战局；即使国势转危，也不必注定崖山惨败 |
| E4 新统一与首都选择 | 明初建国/分封与靖难式权力风险；南北建都、中央与边防的调度矛盾 | 建都南京/北京或其他可行首都，兼顾赋税、京师安全、北方军费与地方兵权；避免一选项永远最优 |
| E5 财政与民变—边敌双重危机 | 明末财政、李自成式大规模起义、后金/清式强敌、袁崇焕式忠臣遭疑 | 可能稳住两边、压住一边失另一边、内战、首都失守或朝廷亡国；疑将、失军费有真实后果 |
| E6 首都危机与入关 | 民变军逼近/进入京师、关外大军伺机入关；提前撤驾、守城、反攻 | 打胜后“京师内乱/北境骚扰”成为可控局部事件；打败则可能失都、退守或亡国；不必一战固定灭亡 |
| E7 近代外来海权冲击 | 鸦片战争式舰炮、贸易/外交与军事差距；后续可扩展甲午式海战、列强干预、制度危机 | 可守国、割地赔款、议和、改革、再战或逐步失势；玩家内政/开放/技术积累真实影响损失，但绝非必胜 |

**“至少可达”是指成功路径能够进入 E0–E7 的主要历史压力类别，不是必须每次完整观看所有历史著名战役的同名重演**。例如只要未失去半壁江山，就无须强制上演“崖山式最后一战”；如果保卫京师成功，民变与边敌可合理收束为一般事件而非自动亡国。

## 3. 用户列举的具体重要抉择与结果

### 3.1 建都南京还是北京
- **南京式南都**：更接近南方粮税与可持续财政，北境军事重心远离京师，前线边军可能逐渐坐大、传令支援迟缓，国防风险取决于道路/漕运、任人、边将军权和战线位置。
- **北京式北都**：更接近北方军令与主力军区，可能改善中枢对北方将领的直接协调，但首都更暴露于边境危机，依赖南粮北运、运河运输、行政成本、财政连续性和北方军粮供给；**不能宣称“定都北京就没有边防风险”**。
- **必须有替代政策**：多都/留都、财政重构、漕运与海运、分设前线指挥、边军轮调、削藩或适度分权。不能把南京=必亡于北军、北京=必亡于财政写死。

### 3.2 加税与民变、不加税与北军缺粮
- **增税**可以增加短期军费，但若灾荒、征收残酷、地方侵吞或长期负担过重，会增加李自成式农民起义的组织和扩张条件。
- **不加税/减税**可能保住民生与政治支持，但若中央收入、运输和征粮改革不足，北方军队可能缺饷缺粮，边敌有机会突破。
- 必须允许有代价的**第三条及更多路**：整治贪墨、削减宫廷/军费浪费、改革土地财政、调配漕运、贸易获利、改革征收、局部减免、联合地方防务、以战止战/议和。这些方案应需要政治支持、时间、人力与真实资源，不能免费解决所有危机。
- 这不是“加税自动生成李自成，不加税自动生成清军”二选一对话。民变领袖与敌军崛起须有真正的势力、人物、军粮、动员和时机链。

### 3.3 北元式草原势力与后金式新敌
- 可以出现北元遗脉式草原联盟残余、北境女真式集团/诸部整合、后金式新政权崛起，互相争夺地盘、缔盟或吸纳部分人口、将领。
- **不同历史原型不是同一支军队的必然改名**：真实历史中的北元与后金不是一个政权简单更名；架空世界可设计它们在战争/兼并/联盟中发生政治重组，但必须有可追溯人口、领土、军权、族群与领导层变化。
- 如果玩家及早消灭或成功整合某些部族，新的北方敌人应有替代的合理成长路径，不可凭空重生同名强敌只为保证进入下一“章节”。

### 3.4 袁崇焕式冤杀、李自成式入京、边敌入关
- **袁崇焕式命运**：受重托的北方守将因猜忌、谣言、战局压力、宫廷派系或真实失误而遭调查、夺权甚至处死；玩家可能救他、相信/不相信证据、代其职或被牵连。**不必每次必然冤杀**。
- **李自成式京师战役**：代表民变军获得持续组织与进京能力，取决于粮饷、灾荒、征兵、地方响应和首都守备。玩家可提前撤离、固守、谈判、决战或围魏救赵。
- **失败与进阶**：打得赢时，民变可能局限为局部骚乱，北敌仍在边境牵制；打不赢时，主角所领导的政权可能失去首都、退到半壁、割据甚至灭亡。**“止步”是此条统一/执政历史进程止步，不意味着主角没有死亡也强行 Game Over**：可在现实条件允许下以败将、流亡者、地方将领或另一路势力继续活着。
- **不是自动晋级**：玩家不能只因点击“击败叛军”就跳到鸦片战争。必须有真实的军队保存、财政稳定、世界时间、技术/外交发展和实际政治条件。

### 3.5 崖山式海战或反攻统一
- 半壁江山和临海偏安可以导向海军、渡江、撤退/突围、保留主力或最后的海上决战；也可以通过北伐/策反/同盟夺回失地，避免落入亡国决战。
- 战争胜负由舰只、航运、粮草、训练、指挥、天气、沿岸补给和敌军行动决定，不预设南方一战必亡。
- **海战系统是后期大工程**，早期可以先在战略层表现船队、航运、海军行动与战损，再在关键阶段开发可玩海战场景；不得用缺少海战引擎作为删除这一长期愿景的理由。

## 4. 技术跃迁：世界加速，不能无因瞬间换装

### 4.1 两条技术轨迹
- **玩家所在中原文明**：典型从唐末式冷兵器/军镇与农业军政起点，经过成体系的火器、军事组织、运输与财政改革，抵达大体清末式的武备能力；如果长期重视开放、贸易、技艺吸收、工匠与训练，可**比现实清代相关能力略强一些**，但不得仅靠投入无限科研点数就跨越到20世纪成熟工业军工/现代军舰压倒一切。
- **外部文明**：同样经历激进变化，最终可能形成优于中原的远洋舰炮、海军组织、工业动员与金融/运输能力。外敌不等玩家统一后才开始科研，也不能突然从草原骑兵直接变成蒸汽舰队而完全没有产业背景。

### 4.2 技术是多维能力与产业链
技术状态必须至少区分：金属加工、火药/枪炮、舰船/海战、生产与运输、兵员训练与编制、税制/行政动员、对外贸易与技术传播。单位仅在有实际武器、制造条件、训练与后勤时才能使用新战法。
- 技术进展可以因为战争刺激、传教/商贸/工匠流动、俘获样机、重大外部冲击、政策持续投资而加快；
- 对外开放与技术重视可改善追赶，不应自动令玩家经济/制度/军事同步满级；
- **范围约束是设计意图，不是绝对数值硬编码**：最成功的开放改革型路线应显著减轻晚期战损、创造战胜/议和机会，但中国式政权不会仅靠一两条政策比已工业化列强超前数百年；
- 技术跃迁需要至少经过“知晓 → 理解/试制 → 生产与筹款 → 训练与部署 → 战场后勤”的环节。跨时代的武器、甲胄和军队不能一帧免费升级。
- 允许不同社会做不同进步：有的国家财政先进但舰炮落后；有的海权国家火器先进但内陆统治薄弱。

### 4.3 历史加速的不合理性要承认并设计
现实唐末到清末跨越约千年；玩家在一生中看到这些，是**幻想性历史压缩（架空史诗规则）**，不是历史发展速度的学术模拟。要同时满足：
1. 世界危机**快速且有因果地**迭代（战争/合并/政权更替，可能几年间进入新结构）；
2. 科技与外部联系在世界背景中具有**早已存在的前置条件或加速机制**，并继续消耗财政/人力/物资；
3. 不因玩家总打赢就奖励免费“朝代升级”；外部文明发展可先于主角政治进度；
4. 年龄与生命继续正常向前，主角在70多岁可能自然死亡，不能靠神奇长寿强制见到鸦片战争。
在设计与 QA 中明确区分“历史主题顺序压缩”和“科技体系换代成本”。如果未经验证不能在单局里体验全部目标，不能悄悄把目标删掉；应修改科技/外部背景和叙事节奏的前置条件并给出可达性证明。

## 5. 剧情压力与玩家成就：可遭遇 ≠ 必输 / 必然按顺序

**时代危机由独立世界触发，玩家影响历史结果。** 时间、地理、人物、兵力和技术共同决定事件是否发生。世界可能几场战争后形成其他帝国，而不是始终被强制叫“唐、宋、明、清”。
- 结构性危机：藩镇独立、强敌轮替、南北失衡、政治财政矛盾、外来舰炮压力。这些压力存在或有条件形成，玩家不能通过躲避让世界永久和平。
- 具体命运可变：旧朝是否灭亡、是否能够统一、是否只剩半壁、海上决战输赢、建都何处、财政与农变是否失控、北军能否入关、近代战争是否失利。
- 玩家在**成功路径**中可以多次化解危机而继续接触新压力，不是一个败局锁住整个游戏；但极其成功也不保证完全没有战争，只会改变战争的起点、规模和影响。
- 如果早败或失去军权，后续“皇帝阶段”的内容可不可达，但主角的个人生涯仍可能继续，身边世界照样随时间演化；可以存档重试关键节点。
- **独立作者剧情**仍由玩家本人最终设计；本文件只是战争机制和历史压力谱系，不替 Dot 写固定皇帝、将领与家庭故事。

## 6. Dot 自主实施边界与排序

**这次是长期世界愿景增量，不允许因此中断现有 youth/finite hero/save/G2 机制交付。**
1. **立刻同步设计约束**：为世界对象预留 `epoch_pressure`, `technology_domains`, `political_institutions`, `capital_location`, `foreign_polities`, `crisis_history` 及其存档/版本兼容边界；但不要从零重构已有 Godot 工程。
2. **先完成少年军旅与三城切片**：从军、军功不公、炮灰队伍、实战+补给+有限情报与存档，达到能实际玩的完整短篇。
3. **第二期世界扩张**：藩镇争战、朝廷有实力又可衰落、玩家拥有/失去军权、多个大势力相互制衡，统一前后的指挥与权力治理。
4. **第三期历史压力链**：以独立世界模拟的“北方多敌—半壁退守或反攻—新统一与都城—财政/民变/边敌复合危机”为先；在每一阶段分别验证胜、败、止步/流亡和异地发展。
5. **第四期科技与海军扩展**：等近代能力树、船舰、产业链和战略战役经过基准测试，再制作崖山式海战、工业舰炮与外来冲突；iPhone 移植须单独决断。
6. **最后验证单生涯通关压力路径**：在**不忽略既有资源、年龄、地理与科技规则**的前提下，构建固定世界种子/玩家策略回放，从约15岁出发，生存并逐步应对 E0–E7，测试至少一条走到鸦片战争式危机的合法路径；也测试在 E3/E5 等处真实失败后的合理止步、偏安/臣属或个人死亡结果。

### 不允许的捷径
- 把每个原型做成“必触发的著名历史事件/必死历史人物”；
- 主角打胜就弹出“下一朝代已解锁”而没有世界演化与技术条件；
- 碰到税收按钮就自动生成李自成，或未加税则自动清军入关；
- 玩家被击败就自动全局游戏结束（除非主角真实死亡）；
- 玩家统一就立即打出游戏片尾；
- 仅凭主角有钱，免费装备几十万兵或造工业舰队；
- 用虚构长寿、轮回或强制继承操控新主角绕过“一生”约束；
- 以开发难度为由擅自删除 E0–E7 的长期可达性目标。

## 7. 验收（文档不是实现）

- **可达性**：一个可重放的合法成功种子/决策序列，在主人公正常人生内依次遭遇 E0 至 E7 的主要压力，且无年龄作弊、资源突变、固定剧本强行胜利，证明至少一条路径能到近代。
- **分叉性**：分别可出现旧朝守住/亡、统一/割据、半壁/守住北方、海战绝境/北伐、建都南京/北京风险不同、民变与北敌得以缓解/失控、近代外战胜/败/议和；并且不同影响真实世界对象。
- **科技边界**：开放改革政策能改善某些领域、重视技术的玩家可比参考清末略强但不会凭空工业化超车；外部海权可合法领先并在玩家未见时发展。
- **失败续玩**：主角败而生还时可成为流亡者、臣属、偏安者或另投势力，不会因为没有“下一时代”就被冻结到原处。
- **不变公理**：三大支柱、WASD/鼠标、少量技能、主角可死/可读档、世界独立运行、真实库存/军令/有限情报全部保留。
- **证据**：世界时间轴、时代危机日志、科技发展与物资账本、分叉条件/军队/城池变化、可重放存档或仿真脚本；真实 Mac 高级战斗与舰炮表现需要另行实测。

## 8. 历史核对提示（供内容制作，不给正式王朝写死名字）

- 唐末五代—宋辽西夏金—南宋元—明清的**真实时间跨度**远超一百年；本作是主题/机制合成，不能将这些国家写成同一年且照搬全部真实人物。
- 北元（元末退出中原后的蒙古政治势力）与后金（1616年建立的女真政权）不是同一政权自动更名。若架空世界要写一支北方政权“演化”到后金式形态，须描述真实的联盟、兼并、族群与制度变化。
- “袁崇焕之死”与“李自成进京”是**不同年份、不同政治因果链**的历史灵感；遇事不应自动强制忠臣冤死或农民起义成功。
- 宋辽西夏金及南宋后期的海上决战并非一个历史时期，作为连续危机需允许时间/外部势力相继演化。
- 参考阅读：Metropolitan Museum of Art, China 500–1000 [https://www.metmuseum.org/de/toah/ht/06/eac]；China 1000–1400 [https://www.metmuseum.org/zh/toah/ht/07/eac]；OpenStax World History 14.1 [https://openstax.org/books/world-history-volume-1/pages/14-1-song-china-and-the-steppe-peoples]。历史事实与架空机制分开记录。

**结论**：完整历史压力链应当能够被一位长期幸存且有能力的主角在同一生中抵达，**而不保证每场战争或王朝结局与真实历史相同**。这是长期世界设计目标；当前 Dot 首先继续已有的 Mac、Godot、三城、少年从军和兵员/经济/存档工作。
