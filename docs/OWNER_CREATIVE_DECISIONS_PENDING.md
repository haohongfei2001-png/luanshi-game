日期：2026-11-08。
目的：纠正此前将“核心技术/基础玩法足以让 Dot 继续开发”误称为“所有创作判断全部结束”。Pro 的默认设计不自动等于用户批准。

## 用户已真正确认（不再重复问）

- 架空中国古代；剧情与自由战争模拟结合；斜俯视 MOBA 尺度 3D 小人。
- **WASD 移动 + 鼠标瞄准 + 技能快捷键**。
- **克制写实的小模型与真实质感**；生产力、服饰、兵器装备受物资约束。
- **个人战斗 / 统军 / 独立世界模拟同等重要**。
- **困难但公平且能复盘失败**，世界独立运行、主角认知有限。
- 主角年龄、伤病、死亡、死后有限视角的结局、存档或节点重试。
- macOS/M5 首先开发、iPhone 后续可选；Dot 自己云端开发，不默认使用 Codex。

## 什么时候判断、谁来决定

### 应先进行的设计判断
OWNER-01/03/04/06/07/08 影响“这是什么游戏、人生如何被体验、战争怎样操作”，应由 Pro 引导、用户选择最终取舍；不可用默认值冒充已确认。

OWNER-02/05/09 应在制作最终内容模板/复杂政治/存档 UX 前决定；Pro 可以给高质量默认提案但必须清楚标注。

### 必须看到原型再判断
攻击打击感、实际 HUD 可读性、士兵数量上限、真实装备外观、镜头距离、长期数值曲线、最终情绪效果。单凭文字无法提前签字通过。Dot 应做可试玩候选并以证据支持选择；用户可以仅在其愿意时评判。

### Dot 仍可继续、不必等待的任务
继续现有 PR #1，完善构建/自动化测试；使用暂定的 WASD、基础技能、20v20、数据结构和确定性世界模拟，修复 bug，建立三城技术基础及资源守恒/情报时延测试；做可替换的架空素材原型。**不要在用户明确判断前将上述未定内容标记“已最终批准”，也不要把已写死的 1–3 小时短篇视为整个项目的最终规模**。

### 如果用户暂时不想逐项确认
默认继续以 Pro 建议方案作为**可逆的临时实现**，记录为 PROVISIONAL，不得代表用户签署产品定稿，也不要求 Dot 每天中断询问。待用户再次进行创作决策时更新对应文档。

## 责任边界

Owner 决定上述高影响力的身份、人物力量、人生长度、政治自由、叙事主题、战略操作、最终目标与存档哲学；Pro 说明代价和提出可落地方案；Dot 自主完成技术、美术生产、剧情细节与测试。**确认某项并不等于用户同意任何费用、账号授权、正式发行或 Dot 持续后台无限运行。**
