# v0.11：同袍自主补证

这是少年军旅中一次可选的营内行动，不是完整友谊、政治或司法系统。
林七、周禾、吴石、田安仍是既有可改的普通军士，不增加未经审定的核心角色。

## 玩家路径与实际后果

真实初阵、返营处理不公并接受委任后，只要还有最初被冒领的军功，可在营中
请求同袍自主联署。需要一小时，粮耗、生产、信使、伤亡与世界同时推进。
先处理这一小时真实损失，再询问活着、在营且亲历初阵的人。
保护后留营的同袍可以在场；新补军士、死者和远方人不能凭空作证。

每人作一次确定性决定，不抽签、不刷新，不按单个忠诚数决定。
- 先前申诉已作证的人显示其旧证词，不再提供第二份补证或奖励。
- 被保护留营者可以因为玩家实际替他承担责难而自愿支持。
- 伤亡积怨大于信任与尊重时，同袍会先顾幸存者，拒绝争功担责。
- 林七、周禾看重保留下来的共同名册及信任，但只有私留名册中实际具名的
  见证人才知道这份副本，其他人不能凭空读取私证。
- 吴石看重亲见的实战本领与信任。
- 田安还看重至少三名亲历幸存者在营互相照应，不独自冒险。
- 信任不足的人可以害怕追责而拒绝，不额外惩罚。其他人不会读取玩家私下的
  选择：即使玩家先前隐忍，仍可有人按亲身经历自愿支持。

每份新联署最多追回一点尚未登记的最初军功，总额不超过真实剩余冒领数。
同时减少队正名下对应军功，真正挣得的战功不变。没有发粮、生成兵员或授予
城池权力。自愿联署者的信任、尊重各增加一点，证词向营中队正、书吏公开；
私藏名册本身仍不会自动公开。关系、具名证词与结果会保存，并保留到后续战斗
或结局，允许真诚支持而非强迫所有人背叛。此段没有多年关系模拟。

后续行粮评议会使用补正后的实际记功，因此补证可能改变队正给粮条件。
**请求行粮评议会定下本次营中记录并关闭补证机会，按钮说明提前提示。**
这避免补证改写既有报价，也避免领取交易口粮后再追回自愿让出的军功。
此前的自动申诉路径原样保留：新动作发生在它之后，不是可以绕过拒证的询问。
拒绝补证者不能在之后重新触发同一补证，也没有另一条旧申诉入口可以强迫作证。

## 因果与保存协议

World8、youth revision 1、所有原字段、来源和身份不变，无新增状态字段或迁移。
新增时间线动作 `comrade_petition` 的 payload revision 为 1：
`revision`, `battle_id`, `decisions`, `restored`；每个 decision 保存
`id`, `sign`, `reason`, `trust`, `respect`, `grievance`。
这套有限的临时人物判断属于 payload v1 行为，不是自动改变旧存档的角色设定。
新补证证词 kind 为 `supplemental_deposition_v1`。

独立历史重演验证实际地点、营地归属、前后时间、阶段和无库存转移，再从原始
战斗及之前行动重新计算完整决定，要求 payload、关系和记功逐值一致。
伪造签名、删除拒绝、重复使用旧证词、改数值、改时间或重复行动均不能加载。
无效加载不替换当前人生。新程序可以逐值恢复真实旧 World8 夹具；旧程序不认识
新动作，会拒绝新补证存档，不承诺反向兼容。
