# Intact native character: reproducible engineering review

Status: isolated source-rig technology experiment. No default character, map,
weapon, save or combat behavior changes. Codex remains PAUSED. This is not an
accepted historical costume, a visual milestone, an actual-player battlefield
movie, or an M5 benchmark.

The seed reconstructs complete 65-joint Quaternius UBC male source and nine
rest-aware UAL motions from two exact package-level CC0 revisions. Original
selected meshes, UVs, weights, skins, bindings and texture bytes are retained,
including raw glTF and full UAL source GLBs. The editable Blender derivative has
packed textures and full actions, with downloaded executable texts disabled.

Workflow `.github/workflows/dot-character-native-seed.yml` checks exact archive
sizes/hashes and embedded license texts, builds locally authored conversion
code, imports Godot, checks all nine motions and the read-only battle adapter,
then creates **only** the absent `dot/character-native-source` branch. An existing
branch is a hard refusal, never a force update. `hosted-source.json` records
actual derivative hashes; subsequent image metadata identifies the generated
commit, not the seed commit or an unverified local tree.

Native close 3.4 m and gameplay-distance 22 m stills are captured in actual Godot
at 2560×1440 and 3840×2160, internal scale 1.0. The optional 23-second native
clip lab movie uses fixed 24 fps simulation time. This is not wall-clock speed,
real-time FPS, a weapon-contact verification, or a rendered army benchmark.
There is no equipped weapon, validated two-handed spear motion, or riding clip.
Original superhero anatomy and modern source clothes remain visibly provisional.

Failure logs and partial results remain artifacts. Pictures are uploaded as a
successful still set only after both native resolutions finish. No old repository
evidence directory is used as a capture output. Source images are not concept
art or Blender render substitutes. Publicly committed/artifact bytes are limited
to the explicitly checked CC0 source and our derivatives. Snow and the disputed
MakeHuman clothes are intentionally not part of this branch.
