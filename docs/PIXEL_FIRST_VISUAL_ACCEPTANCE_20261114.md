## 最新 Owner 要求

Owner 最新明确目标是“非常的清晰、有质感，整个画面非常的自然”，有现代大游戏的整体完成度，
不是粗糙小样。正常游戏里也要看清手、武器、盔甲结构、人物朝向和攻防姿势。
画面须为实际小尺寸人物做适配，不能只在放大的近景展示细节。
“不要有涂抹感”，不要让缩小后的纹理变成昏暗、油腻或脏兮兮的色团。
本条更新覆盖旧文档中将某一种渲染表示当成固定质量目标的说法，其他产品/历史/许可约束不变。

**画质与真实千人性能是目标，全部使用实时3D不是目标。**
共享3D、多方向动画贴图、近中远混合都允许实际比较；尚未选定最终路线。
不把用户询问贴图可能性写成“已决定全体改2D”，也不预设贴图必然更好或更省显存。
当前全部旧画面仍为 ART FAIL / OWNER NOT ACCEPTED。

## 从实际屏幕像素设计完整画面

- 先看正常游玩机位的原生2560×1440和3840×2160画面，再看近景。
  先按Wild Rift参考选择自然的人物屏幕占比，再固定每组对照的投影/size或FOV、中心/朝向/俯角及完整矩阵。
  Field正交size22仅历史回归基线，不把它误写成相机物理距离22米或最新硬门槛。
  必须记录人物实际像素包围盒、真实内部渲染尺寸与比例，不为全军同屏缩小人物。
- 人物靠连贯人体、干净外轮廓、明确手握连接、可读的衣甲分区/甲片层次和动作重心被认出，
  不是靠脏噪声、锐化光边、过亮高光或夸张武器尺寸。
  正常兵、枪盾弓、将领/骑兵须在相同材质语言下保持兵种与朝向辨识。
- 以中尺度结构和受光分面表达体积。细褶、织物/金属细节只能补充结构；
  经缩小/mipmap/压缩后若只剩黑团、油光、糊泥或碎噪点，必须重做，不称“有质感”。
- 整片桥到城门的地形、河岸、道路、树林、建筑、背景与人物应统一尺度、色阶、材料和光照。
  不用遮挡、近景取巧、增亮曝光或堆砌零件掩盖缺少完整形体/构图的问题。
- 合法源、专业母版、高模三角数、复杂节点、烘焙成功和CI绿色都不是艺术通过证明。
  继续保留完整可编辑母版与源授权，让造型、动作和纹理可以真正返工。

## 同源共享3D / 动画贴图 / 混合实测

1. 从同一许可清晰、可编辑的完整人物/动作源建立基线。普通兵共享模板和资源，
   不为每名士兵复制资产。3D允许合理LOD/实例/批处理，贴图允许合适采样与压缩；
   目标是各方案在相近画质/预算下的合理结果，不机械锁定三角数或贴图数量。
2. 不能只用已淘汰旧几何或178MB单人求值缓存代表“共享3D”，再以此宣称贴图胜出。
   若原型尚非优化架构，明确写明；高品质母版可以同时服务近景3D与远景烘焙。
3. 先验证走停、转向、持枪、攻击、防御/受击、死亡与骑乘所需表示，不用静态站姿代替。
   8/16方向只是可测候选，不是质量承诺。检查角度切换、双手握点、长武器边界、
   alpha边缘、阴影、树/城门/单位前后遮挡和深度；不裁枪省图、不用不正确排序掩盖穿插。
4. 同源码、种子、输入、仿真时间/tick、镜头、兵力分别20/100/250/512每方对照。
   保存战斗快照/摘要确认真实攻击、防御、伤亡与镜头外战争未被删减或改成装饰演员。
5. 保存原始正常镜头截图和真实原速录像，披露不足。近景/放大裁片只辅助诊断，
   不替代正常屏幕尺寸的视觉证据。失败稿由制作方主动判退并保留，不让Owner代做初筛。
6. 独立无截图读回的性能流程记录硬件、输出/内部尺寸、平均FPS、P50/P95/P99、
   峰内存、真实纹理驻留/显存与可核实渲染成本。若平台无法测真实显存，写NOT_MEASURED，
   不用ZIP/PNG大小或理论预算冒充。贴图normal/depth通道、mipmap、帧数和方向都计入成本。
   录屏采样率不等于游戏FPS，软件llvmpipe不冒充原生Mac，M1 Virtual不冒充M5。
