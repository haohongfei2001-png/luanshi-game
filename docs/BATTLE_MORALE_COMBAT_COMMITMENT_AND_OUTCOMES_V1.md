# 《乱世》战斗胜负、士气与战斗强迫性｜Owner 决策规格 V1

**2026-11-12｜正式产品决策配套规格**
**Owner 权威**：`PRODUCT_DECISIONS.md §1N`。与既有 §1H 的“双方强将、继任和真实胜负”整合；不改变玩家简单操作、历史玩法按乐趣筛选和正式剧情由 Owner 创作的规则。

## 1. 核心原则

战争不是“杀够多少人/杀死 Boss 就结束”。部队为什么还打、为什么失去阵形、为什么逃跑、为什么有序撤退、为什么投降，必须由其**士气、战斗强迫性、指挥连续性和真实战局**共同决定。

每一场战斗可以有不同结束方式，且战斗结束不一定意味着整支军队覆灭。应区分：
- 战场上的战术结果；
- 当前军事任务是否完成；
- 军队是否仍有组织能力；
- 城池/地区/整个战役的战略归属。

## 2. 四类主要军事结束方式

### 2.1 全歼（敌军全灭）

- 敌方参战兵力被全部杀死，或已没有任何能继续作战的敌方单位；若仍有被俘/投降者，应准确记为俘虏/降兵，不得在战报中伪称“全部杀死”。
- 全歼是可能结果，但不是默认胜利条件，也不要求玩家每场杀光对方。
- 全歼应由战斗、包围、失去退路、拒绝投降、持续抵抗等真实因果产生；不能在战斗结算时自动删除仍存活的军队。

### 2.2 溃败逃散（Rout / Flight）

- 士气崩溃、队伍失去组织，士兵开始逃跑；部分将领可能带亲兵逃走，部分可能被俘、被杀、试图收拢残兵。
- 达到战场结束条件后，明确给玩家一次简单选择：**追击**或**停止追击/收拢部队**。
- 追击可能扩大敌军伤亡、俘获逃兵、缴获装备，也可能导致己方队形散乱、疲劳、脱离主力、遭后卫反击或伏击，甚至错失原定战略目标。
- 不追击可以保全体力、重整队伍、先占据目标，但敌军残部可能逃脱、重组或稍后再战。不能自动追击，也不能把“溃逃”直接等同“全灭”。

### 2.3 战略撤退（Organized Withdrawal）

- 主帅或仍有效的指挥链判断继续作战不利，主动命令部队按计划撤离、向预定地点收拢、保留主力或掩护其他部队。
- 部队仍有阵形、后卫、军令和一定纪律；撤退不等于溃逃。可以放弃阵地/城外战线，却保留大部分军队、装备和指挥体系。
- 撤退可能是战术失败，也可能是完成战略目的后的成功脱离、保存实力或诱敌。**不能仅因对方离开当前地图就默认全军被击溃。**
- 敌军有序撤退时，玩家可以依据战场情况选择继续完成原任务、稳固目标或谨慎跟进；不要求另做复杂追击微操。

### 2.4 投降 / 降服（Surrender）

- 主帅或部队在继续抵抗已无合理希望、退路被切断、士气崩溃、战斗强迫性不足，且投降比继续抵抗更可接受时，可能选择投降。
- 主帅可能主动投降以保全部下，也可能在没有继任者、军令链断裂后被迫降服；个别部队也可能先行投降，其他部队继续战斗。
- 投降结果应区分投降者、被俘者、仍在抵抗者、逃散者；武器、粮草、城池和人员归属按实际结果结算。
- 投降不是必然触发的剧情事件。敌我双方均可能接受、拒绝或提出不同条件；条件和后果由双方处境与制度决定。

**兼容既有任务胜利**：攻占阵地、守住目标、护送冲车、救援、突围/撤离等可以在敌方仍有大量幸存者时结束当前交战。此类应标记为“完成任务/取得局部战术成果”，不可误报为敌军全歼或整支敌军投降。

## 3. 两个独立指标

### 3.1 士气（Morale）：愿不愿意打、还能不能打好

士气是动态状态，概念上可用 0–100 表示，代码内部可用归一化数值。建议至少同时存在：
- **小队/分队士气**：直接影响该队的攻击、防御、阵型、推进和撤退；
- **军队整体军心**：由各分队、将领与战局汇总，不是一条全军共享、所有人瞬间同步的魔法数值；
- **士兵个体差异**：在队伍士气基础上，受伤、目睹长官阵亡、与同伴失散等产生局部变化。

主要影响：
- 战斗效率：攻击时机/准确性/出手意愿、防守反应、承受压力和继续接敌的能力；
- 阵型：保持队列、听从队形调整、前排补位、侧翼响应、受压时的散乱程度；
- 命令：服从速度、命令执行可靠性、是否自行退却或离队；
- 忠诚与组织关系：短期首先影响服从和信任；若低士气、被抛弃、长期欠饷/装备不足或遭错误指挥持续存在，才逐渐影响更持久的忠诚、逃亡、倒戈或离队倾向。**士气低不等于永久忠诚值瞬间归零。**

导致士气下降的因素包括：
- 普通士兵阵亡/负伤，尤其是短时间大量伤亡和身边同伴接连倒下；
- 主将、主帅、亲近军官或军旗/传令链关键人物被杀、被俘、失联；
- 敌强我弱、被突袭、侧翼崩溃、遭包围、退路/桥梁/粮道被切断；
- 阵地、城门、旗号、重要目标失守，援军迟迟未到或补给崩溃；
- 长期疲劳、饥饿、装备不足、连续败战和命令混乱。

导致士气恢复或稳定的因素包括：
- 副将/继任者及时接任并被部队认可；
- 主帅/军官亲自整队、鼓舞、号角/军旗/传令成功；
- 援军抵达、守住重要阵地、完成局部任务或成功击退敌军；
- 友军稳住侧翼、退路重新打开、敌军攻势减弱；
- 休整、补给和队伍重新编组。

**零界点含义**：某支队伍士气降到零，代表其继续正面作战的意愿崩溃，士兵会尝试逃跑、弃械、躲避或投降，队伍阵形和有效战力瓦解；军官也会出现逃离、收拢残兵、尝试继任或投降等行为。军队层面的整体士气崩溃，会迫使主帅在继续抵抗、组织撤退、逃跑或投降之间作出选择。不要让全军因一次远处伤亡而同一帧瞬间溃散；变化应沿小队、附近目击者和实际军令/消息传播。

### 3.2 战斗强迫性（Combat Compulsion）：有没有权威或现实动力让军队必须继续作战

这是与士气不同的第二指标，表示**部队即使不愿意、害怕或已遭挫败，仍有多少制度性权威、纪律、使命压力或现实必要性支撑其留在战场、服从命令和维持抵抗**。它不是攻击力加成，也不是士气的另一个名字。

主要来源：
- **权威与合法性**：政权/朝廷/藩镇/地方中枢的威望、主帅任命是否合法、军队是否认可本地首府和统治者；
- **指挥连续性**：副将、继任者是否明确，命令链是否仍然有效，军旗/号角/传令是否能继续传达；
- **使命与责任**：守卫首都/家园/要塞、掩护友军、保护家属/百姓、完成关键任务的必要性；
- **军纪与组织约束**：训练、军法、部队传统、长期隶属、对军官/同袍的责任，以及违令/逃跑的后果；
- **现实选择空间**：是否有可行退路、是否被包围、是否有可接受的投降条件、援军是否可能到达。

主要作用：
- 决定士气低落时，军队更可能继续坚守、执行命令、组织撤退、逃跑还是投降；
- 影响部队是否服从继任者、能否维持阵形和纪律；
- 高战斗强迫性可以让低士气部队仍然守阵、掩护撤退或服从命令，**但不能凭空恢复勇气、血量或战斗效率**；士气低仍会降低实际战力。
- 低战斗强迫性意味着即使士兵暂时士气尚可，只要使命失去意义、权威不被承认或指挥链崩溃，也可能自行脱离战斗。

**关键例子：主帅阵亡并不等于全军逃跑。**
- 如果一支地方军队的首府/政权威望足够，军令合法，副将和继任制度明确，部队相信新任者仍代表同一权威，则主帅阵亡只造成局部或短暂士气震荡；副将可以接任，军队继续战斗或有序撤退。
- 如果主帅是唯一被认可的权威，没有可接任的副将，政权威望不足，命令链中断，且战局本来已不利，则主帅阵亡可能同时削弱士气与战斗强迫性，触发大范围逃散或投降。
- 同样的主帅阵亡，在不同势力、不同军制、不同首府威望和继任安排下，应有不同结果。

## 4. 两个指标如何共同决定行为

| 士气 | 战斗强迫性 | 更可能出现的行为（不是固定脚本） |
| --- | --- | --- |
| 高 | 高 | 坚定作战、维持阵型、积极执行军令 |
| 高 | 低 | 仍有战斗力，但若目标不值得/命令失效，可能自行脱离或选择保存实力 |
| 低 | 高 | 害怕且战力下降，但可能因军纪/权威/使命继续守阵、掩护、服从有序撤退 |
| 低 | 低 | 更容易溃散、逃跑、倒戈或接受投降；主帅更可能逃跑/投降 |

主帅不是简单读取两个数字后随机选结果。其选择还要考虑剩余兵力、敌我力量对比、任务是否完成、退路、援军、个人性格/利益、继任者、投降条件和政治后果。

## 5. 指挥继任与首府威望

- 主帅、主将、副将、先锋、队正的职位/权力范围必须区分。战场主将死亡，不一定意味着全军最高统帅死亡；全军主帅也可能不在战场。
- 指挥继任应有预先存在的副将/替补/指挥序列，接任需要被所属部队识别并认可，而不是凭空生成新将领。
- 政权或地方首府的威望可支撑合法性和军队战斗强迫性；同一主帅死亡事件，在朝廷正规军、地方藩镇军、临时招募军、盟军中的影响不同。
- 继任成功可以稳定或逐步恢复军心，但不会自动治愈伤势、补回伤亡或恢复弹药/粮草。
- 如果没有继任者，部队可能分裂：部分听从副将、部分跟随亲信、部分逃散、部分继续抵抗；不要全军一刀切。

## 6. 敌军溃逃后的追击决定

敌方达到溃败/逃散条件并结束当前接战后，玩家应获得简单明确的选择：
- **追击**：继续追杀/俘获逃散敌军，可能缴获装备和战马；同时承担疲劳、队形松散、远离主力、遭后卫反击或埋伏的风险。
- **停止追击**：收拢队伍、救治伤员、占据目标、保护冲车/粮道或准备下一战；敌军残部可能逃走并在后续世界中重组。

该选择不要求逐个点击敌兵，不强迫玩家进入漫长的追逐小游戏。可用一次军令/战后决策完成；具体伤亡和俘虏数应按实际追击过程结算。战略撤退与溃逃需要区分，前者通常保留组织和后卫，不应同样被判为无序逃兵。

## 7. 复杂度边界

- 不需要做成大型军事管理软件。玩家只需要看到易懂的战况：军心稳定/动摇/濒临崩溃、指挥链是否仍有效、敌方正在溃退还是有序撤离。
- 士气和战斗强迫性可以在后台按小队/将领/军队聚合，普通兵使用轻量状态机；不需要对万人逐人运行复杂心理 AI。
- 玩家可以通过观察军旗、军官行为、士兵动作、战报和有限侦察了解敌军状态；不要求始终看到敌军精确数值。敌方也不能全知。
- 不要求所有战役都包含全歼、追击、投降等每一种情况；但胜负系统应允许这些自然发生。历史要素仍遵守 `PRODUCT_DECISIONS.md §1K` 的“好玩优先、避免过度复杂”。

## 7A. 属性共享与个体例外：优先批次/编队计算（Owner 2026-11-12）

**不为每个普通士兵单独维护完整攻击、防御、士气和战斗强迫性。** 默认采用三级数据组织：

- **兵种/装备/训练批次模板**：共享攻击、防御、护甲、武器参数、基础生命、训练修正等静态属性。
- **小队/连队/军队状态**：共享当前士气、战斗强迫性、阵型凝聚、命令、目标、补给/疲劳压力和整体战术状态。一个连队中的普通士兵默认读取相同共享值。
- **士兵个体例外**：只保存唯一 ID、位置/动作、当前目标（确实需要时）、生命/伤势、生死/逃散/被俘状态，以及与本批次不同的装备/弹药等。个体受伤、特殊经历、亲卫身份或目击重要事件时，才记录稀疏覆盖值。

因此，某一批同装备普通步兵可以共享相同攻击/防御；整支部队也可共享很多动态数据。近景可见士兵仍然各自移动、出招、受击、死亡，不能将可见战斗简化为一个虚构总人数。士气事件首先影响小队/编队，再按通信/目击向其他单位传播，个体默认继承编队状态。重要将领与主角可独立计算。

## 8. 当前代码差距（研究起点，不是修复完成声明）

当前主线已有基础：
- `battle.gd` 中每名士兵有归一化 `morale`，受到伤害时略降；低于局部阈值会进入 `ROUT`。
- `field_objectives.gd` 有有效战力、溃逃人数、指挥队数和连续崩溃计数，用于任务层结算。
- `officer_corps.gd` 有军官负伤/阵亡、亲卫救援、俘获和副将继任；主官失位只对附近目击者施加局部士气冲击。
- 但当前还没有独立、明确的“战斗强迫性”指标，也没有完整统一的“溃逃追击选择/有序战略撤退/主帅逃跑或投降”决策链。现有固定战损阈值和单场任务结算不能完全代表本规格。

Codex 应在当前已合入的河关代码上增量扩展，保留现有存档/旧版本兼容与任务目标；不要推倒现有系统或一次性实现复杂的全国政治 AI。

## 9. 设计验收原则

同一名主帅被杀，在高首府威望且有副将继任的军队中应能继续作战；在无继任、权威低、已被包围且士气低的军队中可能溃败或投降。相同战损比例也不能必然导出同一结局。全歼、溃逃（可追击/不追击）、有序战略撤退、投降和任务达成需要有明确区分；存活人员、俘虏、逃散者、阵亡者、武器和粮草必须分别结算并可从存档复核。
