2. **每个任务都写可运行代码、跑实际测试、提交 PR 或可追溯 commit**。测试通过/运行画面/性能数据/录像应与对应实际 SHA 绑定，禁止只提交方案或自动生成的艺术效果图。
3. A 一旦稳定，就形成真实绿色 CI 与回退候选。B 每个兵员规模都保留帧时间、战损、摄像机移动连续性证据。C 每个武器先有可玩动作与真实命中，不只是配置数据。D 先证明真实任务目标能在敌军仍活着时结束战役。
4. 性能瓶颈先削减普通士兵的决策复杂度、独立寻路、频繁更新和远景骨骼动画；不优先削减 512v512 兵员或把普通兵变成静态假人。人形近景能分辨脸/手/武器/衣服，远景能分辨阵型。
5. 不用云端模拟 FPS 冒充真实 M5 表现。用户没授权 Mac 访问时，M5 性能验收是 NOT_RUN，其他可独立推进。

## 必须严格区分的状态

- CODED：代码已写但不代表运行成功。
- CI_GREEN：精确提交的完整 CI 已通过。
- RENDERED：实际游戏窗口可操作且有真实图形/战斗录像。
- MAC_ARM64：在具体 macOS arm64 机器上运行，不等于用户 M5。
- M5_60FPS：真实 M5 至少 20 分钟 512v512 战斗帧时间实测通过；未测不得宣称完成。
