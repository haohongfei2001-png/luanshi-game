# 《乱世》剧情世界母本 v0.2：中晚唐式架空战争与灰色忠诚
日期：2026-11-08｜性质：**Pro 根据所有者最新叙事方向形成的提案与系统设计，不等于所有人物姓名、每场战役和结局已由所有者审定。**
权限高于此前“东汉末—魏晋文化默认设定”，但以 PRODUCT_DECISIONS.md 的用户明确决定为最高准则。
完成度：背景和机制可以直接由 Dot 研发；正式主要人物和关键剧情仍须尊重 Owner 创作判断，未指定细节由 Pro 提案、Dot 临时实现且标记 PROVISIONAL。

## 0. 已被用户明确提出并应锁定的剧情公理

1. **参考唐代后期政治环境**：朝廷仍可能掌握国内部分最强的军事力量，但其兵力会因与藩镇争权、边境强敌作战、内部失误而消耗；也可能经改革、援军和政治联盟恢复能力。不能预设“朝廷开局必亡”或“永远无力”。
2. **存在多种阵营生涯**：玩家可追随朝廷、地方势力、边境外敌，或者转换忠诚/自立；人物有现实的利益与风险，行动不自动成功。
3. **被俘不等于死亡或强制 Game Over**：可以被押解、关押、招降、有限自由、交换、逃回或长期服务外方。是否被原朝廷猜忌、报复或再接纳取决于信息、政治、功绩、派系等，允许经历《汉书》中的李陵/苏武式对照，但不固定谁的结局。
4. **背叛的灰度**：主角可能认为仍有可敬的国君与朝廷，也可能从具体遭遇中失望；旧主、藩镇、外方都不必被写成单一善恶标签。
5. **友谊与反目有因果**：好友可能成为部下、同僚、竞争者、不同势力的将领或敌人；好胜、不甘居下、价值观、利益与任务差异、失散与重逢可能积累矛盾，也可和解、互救或和平分道扬镳。不可用单一“忠诚值低于 X 自动背叛”。
6. **历史两层**：边境战争、军权争夺、财政与兵源压力构成不可凭玩家逃避而消失的历史背景；具体战役、人物生死、朝廷是否重新崛起、某次忠诚或叛离结果可在真实世界因果中改变。
7. **剧情重点**：重要战争和人际关键节点安排精心写作的条件分支；大量普通行动通过系统与战报表现，避免重复刷任务。玩家初期对天下影响有限，得到军权/情报/地位后影响可扩大。

## 1. 年代表述：架空但不能伪称严格史实

- **政治主参照：安史之乱后的中晚唐藩镇政治、中央禁军（含神策军经验）、朝廷与边镇相互猜忌。**
- **边境主参照：八世纪后期至九世纪初唐蕃战争、和议与边疆权力变动。** 历史上统一吐蕃帝国在九世纪中叶走向分裂；若游戏希望同时拥有接近九世纪末的“唐末”分裂局势与统一强大的西部外敌，必须明确这是**架空合成时序**，不能暗示真实历史在同一年发生了这些事件。
- 虚构王朝、皇帝、藩镇、西方高原政权的正式名称暂定，**只保留制度结构与冲突机制**。原三城安平救援是第一阶段验证场景，不应被自动认定为最终唯一主线。
- 视觉参照随用户新决定同步为**中晚唐服饰、铁/革/札甲、马匹、军镇和边塞建筑的朴素日常面貌**。不等于“所有唐军必无甲”：财富、职位、军种、供给与战利品决定军备差异。

## 2. 天下不是一条中央“健康条”：政治军事实力模型

**朝廷/地方/边敌均为拥有军队、财政、控制链与内部人物矛盾的势力。** 朝廷的实际能力建议拆为：
- `imperial_field_army`：忠于中央的机动精锐（可强大，但会在实际战争中伤亡）；
- `capital_defense`：都城与直属军镇守备，不能全随意抽空；
- `treasury_and_supply`：财政、粮饷、马匹、道路运力；
- `command_cohesion`：谁真正能使各军遵命、军令传递是否被阻断；
- `legitimacy`：皇帝、朝廷官僚、地方官及居民是否承认诏命；
- `court_factions`：皇帝、监军、禁军统帅、宰辅、边将之间的不同利益。
- `border_pressure`：外敌军队位置、谈判、补给和对内政的牵制。

上述不应压成一个“朝廷强度 = 57%”的万能公式；玩家见到的只是延迟、片面、可能被粉饰的军报与人际观察。朝廷可能这次有效救援，下次猜忌功臣；也可能先失利、后来重整。

主要势力初版建议设为：中枢朝廷、至少两个具有利益差异的地方军镇、西方高原政权（外加边境内部派系）。其他军镇/民间武装可由 Dot 随世界规模增加，不急于制作全国地图。

## 3. 俘虏—异国—归国—政治后果的完整可玩链路

**明确“失去自由”而不等于角色死亡**。建议状态：
`free` → `captured` → (`detained` / `negotiating` / `conditionally_employed` / `exchanged` / `escaped` / `returned` / `defected`)。
若被杀、疾病致死或自然死亡则本局结束；活着仍能经历囚禁、转押、讯问、传递口信、选择是否帮助外方、等待交换、与看守建立关系、尝试逃跑等有限行动。不能因为场景被俘就自动恢复全自由控制或全部装备。

### “李陵 / 苏武”不是二选一脚本
历史原型《汉书》：李陵因战败降匈奴与后来汉廷的处置、误传、家人遭诛相关；苏武被扣押多年后得以归汉。两人事迹属于**西汉**，在本游戏只借鉴“羁留、忠诚证据、政治误判、归国评价”结构，不是唐代历史人物穿越。

可演化结果示例：
- **羁留而不降、交换归国**：仍有功绩与支持者，可能得任用，也可能因多年失联受猜疑；
- **为保全士兵暂接受外方官职**：可以获得生存/行动能力，但归国后面临调查、羞辱、流放或报复，亦可能靠证据、势力保护而重获信任；
- **原朝廷误信“主角教敌军用兵”**：家属、部下受牵连 → 归国无路 → 主角转而加入地方军镇甚至反抗朝廷；也可能通过找到证人或政治变化洗清；
- **主动归附外方**：外方不会因为“投降”就自动信任；可能需要交人质、证明能力，原部众也可能拒从；
- **既被朝廷猜忌又不受外方信任**：在两边成为边缘人，也可与旧友重逢、流亡、尝试自立。

**公平性**：重大“被诬陷/全家受牵连”需要真实信息来源、政治动机、决策链、可获知的警讯和因果日志。不要把被俘固定成“最坏结局”或无可改变的报复惩罚。玩家有权尝试举证、和解或逃离，但不保证有效。

**情报隔离**：玩家在异国不能立即知道朝廷对他的判决；通过信使、俘虏、商旅、间谍和后续会面获知。返回之后也可能发现命令早已签发，不能因玩家读到一封信才启动历史。

## 4. 友情、竞争与反目的多维模型

重要角色至少有：
- `shared_history`：曾救命、结义、共同战斗、分别时间及共同伤亡；
- `status_ambition`：对军职、名望、军权、财富与自主性的追求；
- `recognition`：是否觉得自己的功劳被承认、对封赏与指挥关系是否满意；
- `moral_position`：对百姓、朝廷、战俘、敌方与谋反的底线；
- `trust`：是否相信玩家行为/诺言；
- `current_interests`：其自己/家人/部队所受风险、拥有的资源；
- `beliefs_about_player`：他掌握的玩家行动、谣言和证据，**不是玩家的真实善恶评分**。

示例 A：昔日战友功劳不逊于玩家，战后玩家成为他的上司。若玩家独占功绩、不尊重其部下，他可能请求转任、消极执行、挑战权威或投向地方；若玩家委以实权或共同建立更公平的奖惩关系，他也可能成为长期可信的副将。

示例 B：玩家与好友因不同军令离别，数年后分别在朝廷与地方军镇担任将领。即使两人仍有感情，也会因彼此任务/家眷与军队利益面临对抗；可以谈判、私下放走对方、上报/隐瞒、战场交锋或拒战，不保证所有选项成功。

示例 C：旧友从朝廷转投外方，玩家以为他背叛，后来得知他当时保护被俘士兵或被假军报误导。真实动机依世界生成并记录，**不能为了洗白主角让所有旧友都变无辜**。好友也可能真的野心勃勃并主动牺牲友谊。

### Reunion（重逢）触发必须有真实物理/情报条件
两个角色都存活，且在相同城市/军营/战场，或者合法的信使/谈判渠道实际连通，才能发生重逢；遇见时根据当时关系与利益生成条件台词。不能让已经战死的好友为了完成“剧情节点”重新出现。若主角一生未再相遇，只能留下传言或未知。

## 5. 重要情节骨架：**建议而非已锁定的正式剧本**

**作者锁定的是冲突，不是固定战果。** 下列建议为 Pro 提供给 Dot 的结构模板；具体角色、对话与某次战役的开端和结尾，仍需由 Owner 通过后续审定或明示委托 Pro 自行提案后决定。

1. **年轻边军与朝廷威望**：朝廷曾在边境救援、派遣精兵；玩家或家人可能相信国君愿意保护臣民；也可以开局就对朝廷持怀疑态度。朋友最初同袍或因军令分别。
2. **第一次重大迟疑**：一次真正的边境失利、军粮短缺或监军截令造成未能救援；朝廷可能重整获胜，亦可能猜忌功臣。玩家可尝试援救、举证或改投地方。
3. **俘获与回归（条件支线，不强制所有玩家被俘）**：战败、护送、遭出卖后被俘；留在异国、拒降、暂任职、逃出或归国，触发不同时长的人生、友谊与政治后果。
4. **旧友异路与重逢（条件性）**：晋升/分兵/立场分化之后，两人可能久别重逢；利益冲突可升级为拒命、公开决裂或战场交锋，也可维系友谊。
5. **关键权力转折**：朝廷精锐是否在边疆/藩镇战争中折损，决定国君是否还有实力兑现承诺；玩家军权是否足以改变都城与边境的战争，取决于真实兵力与支持者。
6. **一生的结果**：能成为边关守将、受害忠臣、异国重臣、藩镇将军、割据者、遗恨战死者，或晚年旁观战争。结局依据其实际能够得知的历史信息叙述，长远结果可悬而未决。

## 6. 非线性故事的必要因果/测试

- 朝廷强弱随“确有的军队损耗、军粮与派系”变化；同一世界可出现**朝廷重振**与**朝廷衰弱**两组路径，不应一律崩溃。
- 被俘是一个可以继续进行的**人物状态**，不是故事终局或纯过场；证明“不降仍可能受疑”“暂降不必永远为敌”“外方也未必信任降将”。
- 旧友晋升为玩家部将，可以从信任 → 矛盾 → 拒命/出走/反目，也能通过权力分配与真诚承诺避免；行为从多变量决定。
- 旧友分离数年后，只有实际地理/信使连接才可能重逢；关系既不能强制恶化，也不应自动保持不变。
- 主角不知道朝廷内部某项谕令时，世界也会按因果办理；后续消息到达后，玩家可以作出新选择。
- 不凭玩家选择是否“忠诚”直接决定皇帝善恶或天下大战；平时多为局部影响，只有在军权/证据/资源条件具备时才可能影响政权。
- 玩家遭审判、背叛或战败后应能解释**其当时可以掌握的风险与后续获得的证据**，不能把未预告的随机惩罚当深刻剧情。
- 社会、政治和边疆势力的人物都应有其政治目标与内部利益，不把外敌写成只会侵犯、也不把朝廷写成必定善良或必定腐朽。

## 7. 应由用户最终审定而不是 Dot 自行锁死的创作点

**不要再让用户选择工程细节，但这些是作者意义上的剧情取舍：**
- 王朝最初是否拥有一个具体的、玩家可能信任的国君，还是多任君主/宫廷派系使“朝廷”本就不是同一个人？
- 正式主线是否特别强调“被俘归来遭猜忌”作为多个开局可选的**主要中段支线**，或者其只是少数会触发的人生路径？
- 核心旧友采用“一位贯穿人生、可忠可敌”的中心人物，还是两三位性格不同的旧友共同构成复杂群像？
- 主线主要地理空间是西部边境—朝廷—藩镇三角，还是多条边境并行？
- 最终风格偏“可逆的政治悲剧”还是“混合成功、遗憾与偶然”的史传体叙事？

这些未决创作点不阻塞基础机制：Dot 可实现捕俘状态机、重要 NPC 利益/认知模型、朝廷有限军队和消息传递，但最终大型关键人物/过场叙事不应在未经明确创作委托的情况下视为不可变定稿。

## 8. 设计职责分离

Owner：决定重心与重要人物/主线冲突，选择 Pro 剧情提案；Pro：历史一致性、政治人性与叙事结构、关键节点分支文案、验收规则；Dot：运行中的游戏实现、条件触发、有限视觉演出、文案细化与技术测试。日常 NPC 台词、普通军报、军营支线 Dot 可自主写，但不能将“所有角色忠于玩家”“被俘=永远背叛”写成必然结局。
