# v0.12：回乡旧识与实体乡信

这是少年军旅的一条可选信息链，不是完整的多年友谊或婚恋系统。
平陵辖下乡里的作坊帮工是一名普通、可替换的旧识，不是已经审定的核心好友。
这个人是现有平陵二十名居民中的一员，不新增人口、兵员或生产，也不迁移或死亡。

## 玩家能做什么

1. 在出营前申请既有的回营传令，然后选择“托已安排的信使顺路捎来旧识近况”。
   这是一次顺路托信，不另造信使。原来的平陵一名驻军、十份口粮及逐时消耗不变。
2. 信使在一小时后离营时取信。内容只包含旧识当时知道的本地事实，并在此时冻结。
   沿既有河道再走三小时，到达河曲且实际见到巡队才交信。若遭真实守军截断，
   玩家只知道尚未收到；超过预期可显示延误或失联，不能确认被截杀。
3. 初阵后返回平陵并处理军功事件后，可花一小时去营外城坊探望。旧识有自己的职责：作坊交工时
   可以见面；家中照料或民粮不足时先顾家人，只留下口信，不保证长谈。
   等待、战斗、行军期间，旧识的安排也在变化。见面不重新抽签，也不会改写旧信。
4. 无额外粮食、军功、兵权或关系点奖励。每局一次托信与一次探望，原军旅选择保留。
   探望期间真正断粮死亡会中断行动，不发新近况；本段终点或人生终局关闭新操作。

## 离屏生活与知识

生活是统一时钟和已发生本地事件的确定性投影，不依赖场景是否打开。
临时压缩时段：每天第 0–4、8–16 时在作坊，其余时段照料家中亲人。
真实居民配粮出现缺口后优先等粮，直到下一次本地足额配粮；当地实际易主后避居。
这些条件影响能否见面和信件内容，不是随意抽取结局。
此处不另建逐人农业排班，整体劳动和粮耗仍由已有城市模型结算。

旧识不会读取城市仓库内部、远方战事、玩家军功或私藏证据。
资源紧张的认知来自居民实际配粮事件，而非直接读取城仓数值。
玩家界面只拿到亲收的旧信及本次亲自探望时获得的回答/口信，分列写信、收信时刻。
未收到的内容、信使真实死亡、当前远处生活状态不会进入界面。
终局后，即便底层旧技术场景仍推进世界，乡里生活投影及已知展示也冻结在结束时刻。

## 保存与独立校验

保持 World8、youth revision 1 及所有既有字段。只新增四种有 revision 1 的闭合事件：
- hometown_attach：已安排信使的 ID；
- hometown_letter：真正离营时的固定消息快照；
- hometown_received：亲手接信或在营中收到返还的信；
- hometown_visit：实际开始时刻、见面/口信/中断结果，以及允许获知的快照。

独立重演核对地点、阶段、时刻、本地配粮/易主、信使离营/接触和结局边界。
应有但被删除的发信或收信事件也被拒绝；不能伪造发信时的过去、重复领取或死后补见。
新动作的耗时纳入少年历史检查，存档恢复仍为原子操作。
含新事件的存档还要从种子初态独立重放整个 WorldSim 时钟。只接受已经校验的外部
行动和战斗结果，生产、运输、粮耗、疲劳、围城与递信仍由原来的时钟代码生成，
逐条核对事件及最终世界。删掉完整一小时、改库存/账本后补一条假短缺，均不能通过。
这不是重新打历史逐帧战斗，也不增加能由存档关闭的审计标志；旧有本地军报的专门
校验仍负责显式观察记录，它们不能提供乡里消息。
真实旧 World8 夹具逐值不变，旧人生可以选择新探望；旧程序不识别新事件，反向兼容不承诺。
