# 河关 · 轻重头盔实机对照

每张截图左半为 RC11，右半为修订版，保留 1920×1200 原窗口像素比例。103 号普通枪兵和 70 号重盾兵都来自种子 61112 的实战军籍。双方各有 512 名普通兵。三档模型实际在屏幕里出现，12 组前后镜头中的位置、朝向、动作、伤害、可见军籍及机位逐项一致。

浅盔露出枪兵侧脸、下颌和耳后短布边。盾兵的盔檐集中在眼眉前，长覆颊与收边护颈之间给肩领留出空隙。两种头盔沿用同一套亚光铁、麻布和皮边，材质、动作、兵籍与游戏规则保持原版本。

第一轮的整圈亮沿在逆光中读成帽圈，枪兵背面第 8 步又被树叶挡住。第二轮将环状亮沿撤掉，追加同一兵员第 51、98 步实拍。正常镜头能看出轻重头肩剪影差别，42 米主要靠武器与阵形辨认兵种，脸部细节受像素数限制。[第一次试作和原始遮挡画面](https://github.com/haohongfei2001-png/luanshi-game/actions/runs/43406520018/artifacts/14026919441)

实机使用 Ubuntu 24.04、Godot 4.6.3、Mesa llvmpipe 兼容后端，20 Hz 固定回放。帧率与真实 M5 仍待独立测试。身体网格的近、中、远面数分别由 5265 / 1529 / 528 变为枪兵的 5193 / 1565 / 580，由 5289 / 1553 / 532 变为盾兵的 5297 / 1669 / 600。整库其余 30 个网格按所有属性和索引对照一致。原有单材质批次继续使用。
