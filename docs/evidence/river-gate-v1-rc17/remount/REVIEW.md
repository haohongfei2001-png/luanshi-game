# 河关骑兵实机复查

原始 51 骨战马和四种毛色来自 Wildfire Games《0 A.D.》。可再分发的原马身、毛鬃和尾部贴图接回河关的脚点、衔铁、马鞍、骑手与两轮车，保留战斗尺寸。源许可与修改已随游戏分发。

固定种子 61112，每方 512 名普通兵。第 150 号骑兵在同样的 100 帧内跑过 9.94 米。六个机位可复核相同的角色、战况与动作。[侧身奔跑](moving-profile.jpg) · [三分之四侧面](moving-three-quarter.jpg) · [22 米实际骑阵](formation-22m.jpg) · [同速录像](mounted-pair.mp4)
