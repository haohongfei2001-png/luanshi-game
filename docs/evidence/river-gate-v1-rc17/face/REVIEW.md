# 三类人的面部实机复查

固定种子 61112，在每方 512 名普通兵的河关战役里录了同一弓手、同一敌方军官和主角。左右两图分别取自修改前与修改后。每一对使用同一人的同一刻、同一跟随机位与光照。

旧头部表面重叠产生鼻颊黑斑。去除内部表面后第一版眉眼过淡。第二版保留眉弓、眼睑、耳廓与唇线，实机侧脸保有朝向；近看仍有硬折，正常战场距离主要靠头盔、衣甲与姿势区分。主角用实战输入跑出队列 18.62 米后取景，距最近军士 2.97 米，生命 100。
