# 人物面容实机 A/B

左侧为 `7c9ac667`，右侧为 `bad15cd2`。测试以同一河关正常入口、61112 种子和真实 512+512 普通兵启动。Ubuntu 24.04、Godot 4.6.3、X11/llvmpipe、1920×1200、内部比例 1.0。人物/镜头坐标从 Godot 投影换算到原始分辨率。两侧保存的相机、可见单位序列、军官、士卒、受击与箭数相等。

从项目保存的原始 [HM08 头部源](../../../../tools/art/field_head.json) 发射 2,914 条正面射线，1,352 条先后撞到至少两层前部几何。横向取 x=.011+(i−21)×.023（i=0～42），纵向取 y=6.105+j×.017（j=0～70 且 y≤7.25），只计 z>.9 且稳落三角面内的射线。在外层与下一层距离小于 0.018 源单位的 58 个样本中，55 处面法线绕序相反。原来两侧可见的眼口深处、两颗独立眼珠和强眼线都会落到很小的屏幕区域。保持 CC0 形体来源，以同一雕塑截面的外侧重建连续脸皮、下颌和鼻梁，在上颊与眉骨之间刻出浅眼眶，将眼睑、唇线定位回真实骨点。个体既有的服饰批号稳定选择三种眉形与下颌宽度，主角和军官另作下颌收放。常用近中景共用相同特征，远阵继续采用原低面数头形。头盔、体型比例、服装主颜色保持原样。
