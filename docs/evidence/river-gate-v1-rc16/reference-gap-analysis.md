# 河关 RC16 的实机美术对照

种子 61112，双方各 512 名普通兵、16 名军官，另有玩家。22 米跟随机位、相同操作、第 43 步起枪到第 48 步命中是主比较。在 5.8 米看衣片与握点，在 13 米看步兵接触，在 49–51 米看军阵。等速影片复用同一组输入。原始图保留界面、遮挡、伤亡与同袍。

| 参照的实机作品 | 在河关观察的具体问题与结果 |

| [赵云传：云汉腾龙](https://store.steampowered.com/app/2201710/) | 正常机位中玩家约为数十个像素。保留原机位，在第 48 步能看到主角与敌兵的枪身接触，但阵列中两人贴近仍有枪杆交叠。[22 米军服对照](https://github.com/haohongfei2001-png/luanshi-game/blob/9fc4f0567bd09a42ba60e8479348e99dbbe9a7ca/docs/evidence/river-gate-v1-rc16/garrison/final-personal-contact.jpg) |

目前最明显的差距仍是拥挤时相邻兵器切过上身、近景脸部与肩线雷同、关内建筑和军营的生活细节稀少。双阵营按新军服与动作复核过的镜位及制作来源见[美术实物清单](assets-and-licenses.md)。
