# 马匹母版评估结论

本候选退回，采用文件清单为空。正式集成保留现有马匹。

现有正式马体已经来自 Wildfire Games 的完整 horse_persian。此次对其原表面做一次连续细分，并试接作者的完整 walk / trot 关节轨迹。2560 × 1600、22 米正反与5.3米近镜的五组实机对照保存在本目录 before / after。首轮实拍源码 e8eb995d8050081726be5156f437f804c154286c，归档 84fef2f0ec0b07475c935fc1e0d720484e2df0dd，运行 43563051656。每方512普通兵，记录的战斗事件、位置、生命、坐骑生命、相位均相同。自审发现静态总体收益有限。

原生动作直接接入现有每周期 1/.68 米的行程后，低位支撑蹄样本的离线地面漂移估算达到约0.95至3.19米每秒，参考行速4米每秒。这是烘焙轨迹的换算量，待实机动作检验。接着完整计算脊柱与腹部父骨，再按 prop_saddle 注册座鞍，近档估算仍为约1.53至3.34米每秒。两版原始结果分别见 motion/rejected-parent-freeze.json 与 reports/remount/native.json。源资产和51个绑定骨仍完整保存，尚需按实际行程重定向支撑相位才能采用。

旧版正常/近镜原速影片已经完整保存于 motion/before-normal.mp4 与 before-close.mp4，每条32帧、20Hz、1.6秒，连续真实步骤85至116。运行43563632815在影片生成后因RGBA转JPEG预览失败，后续运行修复转换并从既有影片恢复预览。旧版影片SHA-256见 motion/baseline-video-sha256.txt。候选的连续影片尚未生成，原速前后比较未通过。完整父骨版本仅完成烘焙与轨迹测量，不能引用首轮静帧作为该版本的实机证明。
