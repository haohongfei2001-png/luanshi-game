# RC19 build provenance

RC19 product commit `8ba9daec9b1dbed8717ecef5cfd15ac2e35e0566`, tree `a34d6e66c2caf2da27109d99b1724bf4328ffca7`, exported checkout `9357483bc54c28e0c5d3c04b42dbe5c7e41b4bfd`. Fixed-seed substudies cover six environmental cameras, both armies wearing the fitted issues, bow and spear marches and nine grounded falls. See [the full play record](PLAYTEST.md) and [raw measurements](measurements.json).

The directly distributed Mac ZIP is the original 99706007-byte file. [The archival job](https://github.com/haohongfei2001-png/luanshi-game/actions/runs/43515292103) verified both platform hashes, bundle identifiers and licence texts, and stored the unaltered application and all four recordings at [2db3813aaf94f27cb28dc67af96d76b8a49640d8](https://github.com/haohongfei2001-png/luanshi-game/tree/2db3813aaf94f27cb28dc67af96d76b8a49640d8).

This archive preserves the recorded pre-draw failure as well as the successful subsequent battle. Hosted default Metal stopped at scene_ready/tick 0 in the primary suite and a second fresh machine using the same ZIP; the first scan of that process found 88 main-thread samples in ShaderRD::_compile_version_end under the forward-mobile material update. The first run had no stack for this interval; the repeat captured the trace. The native rendering condition, normal-size image, 100% scale, original data, and failure exit codes are retained. The user's Mac was not used.
