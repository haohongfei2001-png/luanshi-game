# 河关 RC19 美术复查

按真实玩家相机审查。种子 61112，各 512 名普通兵，另有军官和主角。用同一输入同一角度的 1920 × 1200 原窗，配合正式包 24 FPS 原速录制。两次曾退回的环境处理均保留，普通军士的动作保留两军正反向和士兵接敌前后的原速片。

| 项目 | 实机观察 |
|---|---|
| 玩家的第一眼 | 浅靛半披、面向和长枪可在游玩镜头找到；紧贴阵列时军官与普通兵仍容易混淆。 |
| 普通人 | 行进时腰挂裙的上缘随髋，开衩下缘受两腿牵动。弓手带弓前行时腕部有分量。不同兵种仍共用一些相似的头型和盔帽，近处袖缝与颊部有硬折。 |
| 真实接触 | #584 受到同一记长枪命中。实际交锋包含格挡、受击、骑乘、冲车与死亡；弩手倒地收势在地面有支点。密列长杆有投影交错。 |
| 城楼与路线 | 飞檐、门洞和两侧望楼作为一座建筑连接，反向近镜去掉遮挡部分。路面留下进城的磨损石段，形成林、路、城三种清楚的形状。城内屋舍仍重复、桥头柳叶偏碎。 |
| 画面、运行与验收 | 两边 1024 名普通兵在同一战局运行，画面使用完整图形视口。目标设备长测待做。用户尚未认可最终实机美术，状态为 ART_REVIEW_REQUIRED。 |
