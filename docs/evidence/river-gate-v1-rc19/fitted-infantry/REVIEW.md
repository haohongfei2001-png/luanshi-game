# 实机裁衣与行弓

原型取自 RC18 `01bcdb90`。两次修改都在完整的河关场景中比较。第一轮修正了袍摆和袖围，正反阵线全窗中仍只在部分边缘看得出变化。第二轮调整了披肩外侧的服装裁口和持弓步态。枪兵和盾兵的两层披膊都沿实际肩部转动，轻甲只覆盖一侧，盾兵两侧覆盖。弓手软袖前伸时在肘前收口，主角半披前短后垂。衣甲改动建立在已有 Wildfire Games、0 A.D. 的服装上。[原始归属和可编辑来源](../../../../assets/third_party/wildfire_garments/NOTICE.txt)

成衣原先的不少侧裙顶点 100% 随大腿走，裙中线各随左右大腿 50%，腰带没有承重。此次按腰、侧缝和摆边距离重分权重，让髋骨支撑衣服并保留跨步时的开口。枪盾的甲片和衣摆保留原有的 UV。上臂的变化均在袖子，头部、双手、前臂护具和骑乘模型沿用基准。主角的长后角下移并沿肩臂缝改变蒙皮权重。

第二轮还修复了一个实测的步态问题。旧动作在人物局部空间把弓固定在一个角度，人物仍可转身。整段走跑只有手位变化。新的步行、退走及跑步轮转以支撑脚的相位带动肩腕和整张弓，拉弦的另一只手跟随同一握点。共改变弓手的 17 个行进条带，其余 400 条全部逐像素比较，包括九种武器的攻击、放箭及受击、骑乘和持盾招式。已有脚底着地和双手握点回归通过。

拍摄环境为托管 Ubuntu 24.04、Godot 4.6.3、X11 与 llvmpipe，原生画面是 1920×1200，内部比例为 1.0，22 米正常镜头，双方各 512 名普通兵与 16 名军官。影片以 20 Hz 暂停自由时钟并逐逻辑步采集，两侧均以 20 fps 编码，约 5.1 秒的实战运动。原始录制与侧向对照分别保存。宽窗反差主要来自衣袖与弓位的转动，甲片的细节在近景更清楚。原阵列中仍有邻近兵器遮叠。

## 攻门处的倒地动作

第 490 个逻辑步，冲车旁 #761 弩兵已经死亡、计时归零，仍抬起膝和两条靴筒。剑、刀和双剑原来的两踝终态分别在地面下 24.72 厘米与地面上 47.04 厘米。重新为九件装备摆出髋部着地、头侧转、肩靠地、双腿伸展的收势，再沿骨骼关节过渡到静止。九套装备两踝现为 8.0/8.7 厘米，靴网格最低点约 −0.3 厘米。前一轮试作曾在半途出现手腕分离，已剔除。最终握点烘焙误差低于 0.17 毫米。九个倒地条带以外的 408 条与裁衣、行弓版逐像素相同。[九种装备与以前的高度记录](ground-rest/kits.json)、[持握回归](ground-rest/grips.log)

对照两侧均采用第 490 步原冲车机位，种子 61112，24 米，1920×1200，双方损失 180/219，窗内参与比较的 255 名角色完全一致。近景细看同一弩兵，另在 22 米镜头完整追踪了枪兵 #514，从第 28 步生命归零至第 43 步停止运动，第 50 步仍保持静止。这次该处有八种普通兵装备实际产生倒地终态。双剑仅完成了资产品质与九套统一骨骼测试。[攻门整窗](ground-rest/approach-pair.jpg)、[弩兵近景](ground-rest/rest-pair.jpg)、[等速动态对照](ground-rest/equal-speed.mp4)、[实际倒地原片](ground-rest/after/fall.mp4)、[逻辑步、血量与邻近战况](ground-rest/after/fall.json)
