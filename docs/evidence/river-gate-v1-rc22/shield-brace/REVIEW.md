# 22 米同机位盾牌承击

产品从已采用的行军步态 `73a57949a496c6e25a49223205eadde6f357b485` 接续，干净提交为 `d7002fbce0521c4408fb46a0083fe562b6506ac5`。变更为 `tools/art/company_motion.py` 与 `assets/river_gate/figures/company_motion.png`。现场和表格出自 [实际的云端运行](https://github.com/haohongfei2001-png/luanshi-game/actions/runs/43526914760)。

旧反应把盾牌外沿折向持盾人面颊。逆向看红军 678，第一次左侧接触时盾板像斜挂在头顶的板。蓝军 70 的右击也把板面扭出正面，原本前腿已在承重，手和股胯只一起缩回。新动作的板心在左胸之前，左臂弯曲、上缘朝攻击一侧，屈膝后通过手柄将盾向前送回；两侧反应回到同一个守势。盾面、木沿、皮缘、内柄仍是现有左掌的同一刚性对象。最有区别的角度是左击逆向以及右击正向。完整窗口中动作集中在实际受击兵身上，对照时分别位于约 (922,561)、(938,565) 附近。命中后多次来击会重新触发反应，第 191 步红军 678 实际阵亡。

使用河关同一个完整游戏，种子 61112，各 512 名普通兵。测试自动寻找真正的两次有方向格挡并在两个版本精确回放。每段 34 个相邻模拟步，20 Hz 原速，1920×1200、22 米原始正反机位，单段 1.7 秒。Linux Ubuntu 24.04、Godot 4.6.3、Mesa llvmpipe 兼容后端。右击为第 79 步蓝军 70 挡红军 576，生命 26.5379 降至 23.7621；左击为第 188 步红军 678 挡蓝军 162，生命 17.3677 降至 13.2929。136 条位置、血量、朝向、相机、伤亡、来击方向、军阵名单数量和动作状态在前后两个版本逐项相同。后续的连击也来自同一模拟。镜头正反各片都包含真正承击前、承击和后续动作。

新图集中只有 227、409、410 三条发生变化，分别是盾牌普通守姿和左右有侧向的承击。其他 414 条、采用的行军和九武器攻击全部与前一个动作版本逐字节相同。直接读取已烘焙 RGBA16 分量，按左手、木盾原始上沿和头部参考点计算，全周期最小间距左击从 8.04 厘米至 22.96 厘米，右击从 13.21 厘米至 22.96 厘米。这是曲面采样间距。扶盾和剑手合计的最大腕口偏差低于 0.15 毫米，支撑脚全程位移为 0。36 条反应与 9 个兵器握持的既有测试通过。保持相同图集尺寸、顶点数、实例数与实时采样代码。

原图为 Godot 窗口；正反双向的原速视频从连续窗口采样编码。本次只核对盾牌，桥面、城门、穿行体验与真实 M5 帧时另外验收。摄影和独立的采样脚本已随 [工作流](../../../../.github/workflows/shield-brace-window.yml) 保留。
