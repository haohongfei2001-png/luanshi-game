# 桥头到城门的正常游玩镜头

| 项目的观察参照 | 本版实机观察 |
|---|---|
| 赵云传、英雄联盟的俯视操作距离 | 22 米正交镜头里，木桥从左下通往右上门洞。玩家有浅色披肩和两段足边标记，摄像机在桥头交锋时保持原位。 |
| 王者荣耀的角色轮廓与色块 | 靛蓝、茜红分布在肩袖和护具边，不靠全身发光辨队。人和马叠在一起时，后排的手和枪头仍较难读。 |
| 全面战争·三国的部队纵深 | 桥后方的士兵按编制过桥，先上东岸的两队掩护后续。军阵在窄桥上有纵深，出口处骑兵仍会挤在一起。 |
| 战意的盾枪、真·三国无双 起源的发力 | 普通枪兵按承重脚换肩，盾兵依来击方向屈膝、收臂，再回守。斜背角的侧向承击比正面的盾面开合更清楚。 |
| 帝国时代 IV 的城防地标、燕云十六声的桥岸 | 绑扎木架、木门楼、石头桥台和官道组成实际通路。近桥外侧岸线仍有一段过直。 |
| 炽焰帝国 II 的个人与队伍层次 | 主角能借先锋掩护进枪、退回、传令。零星分开的步兵容易跟，骑队合拢的几秒仍难持续跟住同一人。 |
