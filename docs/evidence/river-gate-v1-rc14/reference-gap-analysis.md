# 河关视觉对照与退回记录

本轮查看了仓库指定的八款游戏的实际画面。下表记录在河关正常 22 米镜头里影响体验的差距。参考游戏的美术归各自权利人；仓库内的战斗图全部取自河关。[正常游玩原图](normal-camera-before-after/after.png) · [当场动作](combat-normal-speed.mp4)

| 对照作品及观察位置 | 河关画面的差距与本次实际处理 |
|---|---|
| [《赵云传：云汉腾龙》攻门](https://store.steampowered.com/app/2201710/Three_Kingdoms_Zhao_Yun/) | 固定跟随到军阵里时，玩家的枪杆与敌兵交叉。保留 22 米机位和原有身材比例，以第 43 步的起手与第 48 步的命中检查披挂和握点。[未裁剪对照](normal-camera-before-after/) |
| [《王者荣耀》地图](https://www.honorofkings.com/global-en/) | 旧草地与人物衣甲同样嘈杂；尝试把草地整体画浅又丢了材质。实作保留大块明暗，把矮草和实土放回路沿。普通兵人脸、手部和树冠仍有明显质量差距。[试作记录](STUDIES.md) |
| [《全面战争：三国》攻城](https://asia.sega.com/totalwar-three-kingdoms/en/) | 远阵中的马匹、军旗需要更明确的结构，改造鞍具与布旗垂落形状，让军旗、马身和骑手分开阅读。旗杆与斜穿的长枪还会重叠。[51 米军阵](wide.png) |
| [《战意》盾枪线](https://store.steampowered.com/app/835570/Conquerors_Blade/) | 盾兵肩腋、甲裙和握盾侧轮廓挤成一块。甲身与肩口分开，裙甲从腰带分片垂落；保留有伤害记录的原位密集格挡。[盾手窗口](shield-pair.jpg) |
| [《真·三国无双 起源》多人接触](https://www.koeitecmoamerica.com/games/dynasty-warriors-origins/) | 原弓手一松弦就出现飞箭，弦上却没有箭。加入手指与弓弦之间的实体箭，按原时刻交给弹道；步兵的移动、起势与接触使用同一回放同步检查。[逐步记录](bow/frames.json) · [原速度回放](bow/equal-speed.mp4) |
| [《帝国时代 IV》中国文明](https://www.ageofempires.com/games/age-of-empires-iv/civilizations/chinese/) | 中桥、河岸和道路的连接缺少用途，按河床排布桥台、岸桩和浅底木舟。桥、门楼、院落仍为当前地图的实际可达空间。[中桥](river-bank.jpg) |
| [《燕云十六声》河岸与衣装](https://store.steampowered.com/app/3564740/Where_Winds_Meet/) | 水穿过船底破坏尺度感；已按船壳吃水轮廓切分河面。步弓手头巾与甲兵服装各有实际轮廓。河关的营造物种类和衣甲身份层次仍较少。[舟与岸](river-bank.jpg) · [头巾背侧](bow/headcloth-side.jpg) |
| [《炽焰帝国 II》英雄与阵线](https://steamcommunity.com/app/1132210/screenshots/) | 战时在前阵里既要追踪枪手也要看军令与战线。保持标准 HUD，在同一场战斗中开军议、发号、回到操作者并查看破门。[部署至驻营的记录](PLAYTEST.md) |

最先处理的四处是兵种服装与持握、弓手搭箭连续性、官道与草场的材质区分，以及河岸物件与树冠。双箭囊和船舱进水在原窗口消失；盾侧手、群体步态和内陆林冠仍需复做。不同游戏中的人物、武器、服饰及地图图像均未被复制进项目。

后续成熟资产的对照还采用《烽沙》的营寨与军阵、《帝国神话》的骑装分层、《The Valiant》的普通兵占屏比例和交战中的任务提示。[《烽沙》](https://store.steampowered.com/app/1733690/Mandate_Order/) · [《帝国神话》](https://store.steampowered.com/app/1371580/) · [《The Valiant》](https://store.steampowered.com/app/959860/)
