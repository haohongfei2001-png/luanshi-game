# 普通游玩距离的兵种剪影试验（未进入安装包）

[可复现源码与云端对照](https://github.com/haohongfei2001-png/luanshi-game/actions/runs/43349512546)使用固定种子 61112，在两个独立 Godot 4.6.3 图形窗口中，从同一军议出战，正常跑向敌兵，以相同输入按下普攻。实际 1920×1200、跟随镜头 22 m、100% 内部分辨率、512+512 名普通兵。两次真实接敌的输入、士兵坐标、距离、血量和相机角度完全相同：[两个采样时刻](raw/field-dress-contact.json)。敌兵 584 在第 48 步由 62 降至 39.76。

[完整候选画面的观看副本](field-dress-window.jpg) · [同像素裁切，左 RC7、右试验](field-dress-contact-pair.jpg)。原窗口无损 PNG 在上列运行的 normal-camera-before-after 附件。候选模型重做了弓手箭囊与斜肩护布、枪兵的窄背甲、盾兵覆大腿的外甲和轻兵的腰囊。装备共享原有骨架与图集，未改变射程或命中。全图观看副本 SHA-256 `e04018931a6a7e436af380ffe0733559bcfb41bcf957ad195a566cd20b8e528c`，等像素对照 `f063c24feec7ee1bc63a7f94cacb415ec891a9bb54d11270c3c2ba15775883e2`。实机使用 Node 重烘焙的 glTF SHA-256 `e3f9b0a9dd003bfdeb4c3e4ca575f1d9f005b1aff7374df2db71442f0c2d6d01`。

**画面裁决**：斜背箭囊、冷灰背甲和绛披更易分开，但按实际大小看，常兵仍是重复的直身轮廓，拥挤时像一排相似的小偶；细枪杆和地图底色所占注意力仍过大。没有用调色、放大裁切或附件成功来宣称美术通过，没有把这个试验合入 RC7。
