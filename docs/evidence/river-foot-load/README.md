# 河关 · 枪盾兵负重与接敌

两个实际游戏源码从同一个入战动作开始，固定种子 61112，双方各 512 名普通兵。73 帧普通 22 米跟随动作复演了同一组键鼠输入，第 43 步起枪，第 48 步命中 584 号敌兵，生命 62 → 39.7627。另一段 68 帧位于同一排枪盾兵的固定 22 米阵线，收录前进、交错和接敌，结束时双方命中计数均为 233 / 122。两套实拍的轨迹逐项相同。图中左半是基线，右半是修订。画面取自 1920×1200、内部比例 1 的真实 Godot 兼容渲染；文件里的两段原视频保留原尺寸。

| 原像素取样 | 能看到的动作 |
|---|---|
| [正常跟随第一击](first-blow.jpg) | 右侧敌军开始压低枪线；持盾步兵的头肩向板后收 |
| [跟随接近中的枪手与后排](follow.jpg) | 有目标的前排向前承担长杆的重量 |
| [进阵](advance.jpg) | 盾手贴着前臂携行，后排仍持原行军姿态 |
| [同一阵线四个连续时刻](sequence.jpg) | 两版同时间顺序，脚步、兵籍和冲车位置一致 |

原版已有两种枪盾携行，但用相似幅度执行每一步。第一轮改变肩胯和肘的承重后，静举枪尖单周期幅度从 0.032 米变成 0.869 米，在待步队列中过大。第二轮降至 0.156 米。带枪前手在实烘焙里的最大偏离为 0.128 毫米，原携行最大腕缝为 0.172 毫米。36 条步兵携行的两足跟随原始数据，102 条携行的命中关键姿势偏差为零。普通步兵只有已取得、位于面前且临近的真实目标会触发接敌准备。冲车附近部分未接敌步兵仍有相近剪影；本次未测实际 M5 性能。
