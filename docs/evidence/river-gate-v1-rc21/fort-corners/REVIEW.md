# 河关城楼、内庭与城墙的实际改动

同一批攻守双方各 512 名普通兵、各 16 名军官和玩家。种子 61112，第 490 步，军中累计命中 975 / 739，伤亡 180 / 219。两个版本的四张原窗逐一比较镜头、可见士兵编号、生命与交锋计数。城门全景里有 594 名普通兵处于画框，双向箭楼与内庭守军仍在原地。

| 视角 | 实际观察 |
|---|---|
| [城门全景](gate-pair.jpg) | 四角使用有收分的砌体，楼顶留出木架和瓦脊。两侧门廊、既有攻门入口与门前冲车仍在同一位置。 |
| [22 米的城角](turn-pair.jpg) | 面对前排士兵的屋面按原来的视线判断切开，斜坡和士兵脚下的墙面保持连续。 |
| [墙上弩手](ranks-pair.jpg) | 架高的值守平台、里侧行走面和前沿区分开。两军直射线与弩手位置使用与 RC20 相同的数据。 |
| [内庭战斗](court-pair.jpg) | 之前的四栋同款房屋分成前排兵舍与后侧库房，相对两列朝向院内。全段屋面可以在玩家经过时退开，墙、廊柱和屋内木架保留。 |

第一稿塔基过亮，第二稿侧墙较旧版厚实但营房外轮廓几乎完全一样。第三稿原地替换了两种建筑，近窗看见守卒站进屋内。最后把住处与库房沿同一侧墙向后挪 5.2 米，保留守军的自然部署，内庭仍可见通向后门的路。上墙士兵的接触与屋顶遮挡分别检查。土质操场仍偏空，部分木材在远镜下偏黄。[每个机位的真实输入](after/views.json) · [城建资产的原作者与 CC BY-SA 授权](../../../../assets/third_party/wildfire_gate/NOTICE.txt)
