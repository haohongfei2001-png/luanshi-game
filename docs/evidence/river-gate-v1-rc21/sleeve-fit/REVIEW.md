# 河关 RC20 普通兵袖甲实机退稿

保留 RC20 `126091196db530aa7ec13de61f839c9c41cac24b` 的衣服。这两版只留在独立美术分支，主候选包继续使用原版。

第一版在 Wildfire 0 A.D. 三件已登记的衣甲上重切腋下弧线、平滑肘权重、修短肩片并收拢原有袖口。近镜稍干净，正常游玩距离的变化很小。第二版从原有六角袖口继续向前臂放布，对弩手、枪兵和盾卫分别采用 17.7、15.2、12.8 厘米的基础放量。刀枪兵垂手近镜能看到连续的前臂布料，但弩兵抱弩的拐角依然生硬，部分深色袖子更显臃肿。22 米顺光、逆向和玩家命中三个完整窗口均不足以支持把它并入产品。

原始衣甲面数为枪兵 354、盾卫 474、弓弩 426。第一版变为 750、874、844；第二版分别为 602、724、692。实际每种 LOD 复用同一件外衣，因此 248～266 个额外三角形会随可见角色反复绘制。本次没有做帧时验收。两版沿用仓库已有 Wildfire Games CC BY-SA 3.0 服装与合法来源，现有安装包不涉及新增归属。

实拍使用 Godot 4.6.3、Linux 24.04 Mesa llvmpipe、种子 61112、两军各 512 名普通兵。原始静帧 1920×1200，内部缩放 1.0。双向阵线固定第 41 步。长枪手 37、弓手 94、盾卫 38 和弩手 569 的近镜为 5.8 米。同一击锁定敌兵 584 的 HP 从 62 降到 39.7627。走位记录为 22 米、20 个仿真步/秒、84 步，枪兵 37 实际走了 7.320 米。前后镜头、名单、攻击、朝向、弹药和步幅记录比较全部通过。

比较第一版时看到了视频接触表的方块，第二版改为从 Godot 实际渲染后直接写无损 PNG，再按恒定时间编码。用于时序质量判断的图保留原像素，视频缩略图不足以判断衣形。目录中的 `before/`、`after/` 含七种现场窗、可下载等速源片和原始来源帧，`line.json`、`input.json`、`film.json` 可复核。
