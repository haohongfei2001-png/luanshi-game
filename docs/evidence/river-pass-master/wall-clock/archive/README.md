# Bounded persistence and independent failure handling

`native_evidence_bundle.py SOURCE FRESH_OUTPUT` creates a curated evidence bundle outside the raw source. Each capture retains at most ten selected original-resolution JPEGs: first/last, temporal quartiles and first available troop contact, block, player impact, visible mounted hero and player damage. Missing events do not get substitute captions or invented frames. Every sampled JPEG's SHA256 and filename is retained in bundle.json, and the original precise timing/state JSONL remains intact. Complete encoded MP4 bytes are copied, not shortened or re-encoded; files over64MiB become ordered exact byte chunks with individual and complete hashes. Concatenate those chunks in manifest order to recover the original complete file.

**All raw frames are NOT persistently delivered.** Unselected JPEGs remain only on the transient runner until its ordinary cleanup. No lossless PNG, lossless video or complete-raw claim is made. JPEG and H.264 remain lossy. The full VFR movie plus timing/hash manifest, selected native stills and source SHA is the review/recovery entrance.

`archive_native_world.py` now curates before its traversal, so thousands of raw frame JPEGs/previews cannot be committed accidentally. Git copies are capped at240MiB including generated previews; skipped material is named in archive.json instead of silently disappearing. Large movie chunks are for artifacts, not Git. The source bundle manifest remains authoritative for complete movie recovery.

**Required runner integration:** upload each curated file/chunk individually, or groups bounded below128MiB. Do not point upload-artifact at the original raw output tree or at all chunks as one giant archive. Curator prints no claim that upload happened. Its max64MiB payload size makes individual retrieval bounded, but the workflow must preserve this partition. Set evidence-curation/upload steps to run after failed capture as well (`if: always()`), retaining failure journals. Raw source cleanup is deliberately not performed by this tool.

Optional QHD and UHD wall-clock capture/encoding failures are independently journaled in evidence-status.json. A disk/focus/readback/encoder failure no longer prevents the other mode or the existing independent simulation-time movie. Capture failures remain in the final list and final delivery exits1; it does not print the global PASS marker. Clean performance runs still happen first in separate no-readback processes. Cancellation/system-exit is not swallowed.

Local unit coverage creates100 fake sample files, retains no more than10, verifies all100 hashes, reassembles a chunked fake movie byte-for-byte and verifies its full SHA. A synthetic blocked capture records NOT_PASSED while an independent movie step still runs. This is archive/control-flow verification, not real footage or successful artifact publication.
