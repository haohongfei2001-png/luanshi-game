# 正常 22 米的朋友、对手与主角

种子 61112，在 512 对 512 的军队中，各自取第 43 步起手、第 48 步命中作为跟随视角对照。兵阵取另一刻并把镜头转过 180 度。两军位置、朝向、装备、光照与实战伤亡在前后相同。正面可见友军 161、敌军 107，反向为 158、126。

第一版肩部太橙，第二版仍容易让红军弓手的脸与衣料连在一起。第三版回到较沉的绛色，暗交领保留在向阳肩膀与脸之间。主角的浅靛半披只落在衣料上，军官铁甲、马具和兵器保持材质本色。窄门和前排兵器仍有部分遮挡。
