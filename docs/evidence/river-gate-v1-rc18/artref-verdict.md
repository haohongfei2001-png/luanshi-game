# 河关实机美术审核

| 游玩距离与对象 | 已看到的变化 | 仍看得见的问题 |
| --- | --- | --- |
| 22 米主角、敌军与正面接触 | 在固定种子、原起手和命中的全窗核对方向，真实掉血。步兵衣身、不同武器和持械步态都在实际军阵中。 | 普通兵数量多时，武器投影交叠；单靠肤色难在一个完整窗口辨认个人。 |
| 5–8 米弓手、军官、主角 | 颊边、嘴角旧黑斑褪去，眉弓与眼睑仍清楚，主角从阵中跑出后从正、侧两面检查。 | 鼻翼和某些肩褶仍显硬，个别军士面貌重复。 |
| 骑兵侧面、斜侧面、22 米、42 米骑阵 | 鬃体有连续边缘，马颈、肩胛和后腿有可读姿态，四种毛色能落在同一队。 | 缰具可能被同排枪杆挡住；在宽镜里浅灰与深褐毛色比脸更有辨识度。 |
| 城关、沿岸与大队 | 原河关堡门、护送冲车、中桥、官道和军队实际进入原生镜头。正常速度战役从布阵到回营。 | 窄桥和门洞内前景经常部分遮住人物，俯看瓦坡和兵阵较为整齐重复。 |
