# Same-source representation comparison, not a shipping decision

User priority is image quality and thousand-soldier performance, not mandatory
3D. Compare reasonable shared3D/VAT LOD,8/16-direction animated sprites and
near/mid/far hybrids. Every ordinary soldier shares a template; never duplicate
178MB per actor or force near-view geometry on distant units to bias results.

Common prerequisite: intact Guardian308-control/79-deform rig with licensed
UAL43-clip source. Initial rest-axis/limb-ratio transfer uses author native IK
feet and FK arms, not donor bone translations pasted onto another skeleton.
The first local50 Idle/Walk poses evaluated successfully; limb ratio1.150631.
Foot-contact, full-body silhouette, held weapon and source-look verification
are still pending. `retarget_probe.py` is NOT an approved animation converter.
Full named rig/constraints/rest/weights and19 visible mesh objects remain native.
`native-interface.json` records which meshes use Armature, cage, subdivision,
Multires, particle emitters and bone/object parenting. Coat1373-point DQ proof
must not be generalized to those other18 meshes or to remodeled garments.

The original source includes a professional2.416m staff:1322-vertex simple
and9148-vertex detailed variants, both attached to original rig_weapon. It is
a possible licensed grip/LOD diagnostic, not historically approved military art.
No new stick/cylinder substitutes are considered equivalent weapon quality.

Material boundary: source diffuse-only+labelled matte migration can provide
identical inputs for a technical comparison. Old layered skin/specular shaders
are not yet equivalent, and Chinese art quality is not accepted. Both formats
must use the same declared migration. No clay result may be called full source
look or approved modern animation style. Particle hair limitations are explicit.

Acceptance contract: actual Field orthogonal size22, original2K/4K pixels,
same seed/tick/time and20/100/250/512 per side. Separate render-only microbench
from real Battle full-chain measurements; preserve actual simulation, attack,
defense, casualties and offscreen advance. Review hands/weapon connections,
armor layers, orientation, natural motion, alpha/mipmap/compression, shadow
and tree/gate occlusion at native screen size, not magnified portraits.
Atlas dimensions follow full animated body+weapon bounds and margins, never
cropping weapons or assuming64px characters suffice. Record real texture/GPU
allocation and peak memory, not only PNG download bytes. No M5 claim.

Default game/Mac engine unchanged. Next: finish common motion/foot/grip checks,
then one same-source Godot render-and-bake slice before army-scale conclusions.
