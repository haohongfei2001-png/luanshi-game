# 桥头老柳的实机审片

种子 61112 的同一场 512 对 512 河关战役，使用 Godot 4.6.3、1920 × 1200 原始跟随窗口、原生画质与 4× MSAA。镜头包含两岸、桥上接敌和靠船处。四处机位前后的入镜兵员摘要、位置、镜头、伤亡、命中和城门进度完全相同。[比较记录](after/views.json) · [关前原始对照](bridge-pair.jpg) · [沿岸反向近镜](landing-pair.jpg)

早期整根移植的柳树在俯视下成为一团亮绿，挡住原有树干；只保留几个下垂叶片又让树冠从某些方向消失。最终保留沿河斜出的老树根、主干和七根主枝，将 Wildfire Games 柳树的多面树叶逐枝重新定形。枝尖挂叶与岸线间留出空隙，军队落脚处和桥面可见。几枝垂柳仍重复类似的弧面，近看时可继续区分长短与疏密。

原件与再分发条款见 [资源鸣谢](../../../../assets/third_party/wildfire_willow/NOTICE.txt)。复拍脚本为 `tests/ford_willow_view.gd`，[最终四机位与日志](https://github.com/haohongfei2001-png/luanshi-game/actions/runs/43514420407)。底图曾分别退回为 [整球](https://github.com/haohongfei2001-png/luanshi-game/tree/5b5d48ab83e902e62b3d6f1641d86d1be981737f/docs/evidence/river-gate-v1-rc20/ford-willows) 和 [侧向缺叶](https://github.com/haohongfei2001-png/luanshi-game/tree/c71b4a7fd12992edf8390329c43223ca54d6f680/docs/evidence/river-gate-v1-rc20/ford-willows)。
