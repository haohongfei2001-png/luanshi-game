# 产品决策记录与权限边界 / Product decisions v1
状态：**产品方向已冻结；少量发行/财务决定留到真正需要时由所有者批准。**
责任：所有者 = 用户；Pro = 设计与独立评审；Dot = 云端实施与项目推进。

## A. 所有者已确定，不得由 Dot 擅自改变

1. **类型**：单机、架空中国古代、剧情 RPG 与自由战争模拟结合。不是纯 MOBA、固定关卡塔防、纯策略桌游或多人在线游戏。
2. **美术和操作**：斜俯视、MOBA 尺度的细致 3D 小人；主角可直接移动、普攻、使用少量技能，并指挥士兵。重要故事可使用立绘、动画或过场。
3. **时代与资源**：社会贫富服饰有节制，甲胄简陋或参差，装备和物资受时代生产力约束；资源来自真实生产、占领、缴获、征发或掠夺，而非凭空刷出。
4. **战争**：士兵可被招募、收服、训练、编组、装备；真实交战、伤亡、溃逃、投降；没有武器的士兵应可见。战场从小队成长为军团；百万级仅可能作为后期、经性能验证的战略规模，不要求百万独立 3D AI 同屏。
5. **世界独立性**：玩家看不到的城池会失陷，将领会做决定，援军会迟到，阵前可能倒戈；行动必须基于人物的有限信息并由因果产生，不能为了戏剧性作弊。
6. **人物生命**：主角衰老、疾病、旧伤、战死及自然死亡；死亡即该局结束，给出玩家可合理知晓的结局，未来留有悬念。允许旧存档/人生节点回溯；无多代继承。
7. **故事意义**：胜利不必圆满，悲剧可以发生但不强制；玩家行动必须有意义。
8. **平台**：macOS / Apple Silicon（用户 MacBook Air M5）先验证；iPhone 是未来候选，不同时做首发。
9. **开发方式**：Dot 使用自己的云电脑直接研发和测试、提交公开 GitHub 仓库。**默认不使用 Codex，不连接用户 Mac**。Pro 做设计与审查，不承担必须实时在线的开发环节。
10. **项目仓库**：https://github.com/haohongfei2001-png/luanshi-game （public；未选开源许可证）。

## B. 采用的默认设计规范（Pro 提议，可由所有者以后覆盖）

- **美学**：克制、朴素、低奇幻/无超自然技能；中国历史物质文化作参考，但避免假装严谨复原特定朝代。不卡通、不过度华丽、不过度血腥。
- **体验权重**：即时战斗与军令 > 战争因果与补给 > 人物关系与叙事 > 城市经营深度。城市经营为战争与人物服务，不做复杂税务/工商业模拟器。
- **操控**：Mac 键鼠优先，技能数量少；随军权成长，从直接指挥小队变成通过将领管理军团，不牺牲角色近战手感。
- **游戏节奏**：可暂停战略与剧情；战斗实时；世界时间统一但分层模拟，允许行军、休养、治理推动多年。
- **首个可完成产品**：先制作真正有开端、发展、结局、可重复游玩的独立小型版本，再继续扩展宏大版。**完成一个技术原型或首个小版本并不等于最初整体愿景全部完成**。
- **宣传与授权**：第一阶段不购买素材/服务，不创建收费账户；所有合入代码和素材的知识产权来源明确。公开仓库 ≠ 授权第三方任意使用素材。
- **质量**：首先确保能运行、能完成一局、能回档、世界不作弊，随后提升画面和演出；AI 测试结果和真实设备运行严格区分。

这些默认规范是推进工作的授权，不是声称所有者逐项表示过同意。若未来与用户的新指令冲突，以用户明确的新决定为准，并在本文件留痕。

## C. 必须由所有者亲自授权的事项（现在不阻塞代码开发）

- 任何**新增收费**、购买素材/服务/算力、会员注册、支付或预算调整（当前预算增量默认为零）。
- 允许 Dot/Codex/其他代理连接用户的**本地电脑**、个人账号或第三方私有数据；启用 Codex 默认不允许。
- **正式外部发行**、提交 App Store / Steam、价格、商标/最终名称、开源许可证，以及 Apple 证书与签名。
- 超出核心设计的重大转向：改成多人联网、纯策略/纯手机、魔法主导、去除衰老死亡、放弃有限情报、取消世界模拟。
- 确认最终产品是否达到本人主观意义上的“好玩和完整”。这一判断不能被单元测试完全代替。

程序架构、文件命名、算法、Godot 版本小升级、单元测试、NPC 名字、初期故事台词、数值微调、场景构图、占位资源、普通技术依赖（免费且许可证允许）、测试、修复、优化、发布候选包制作等均由 Dot 自主进行。
