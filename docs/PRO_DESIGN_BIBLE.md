# 《乱世》（暂名）游戏设计母本 v1 — Pro 交付

## 一句话体验

在独立演化的架空中国古代乱世中，玩家用有限生命、物资、军权和情报从小校走向可能统兵天下；近身战斗可以以一敌百，却未必有时间或权力救下所有人。

## 四根支柱与优先级

1. **战斗可操作**：MOBA 式斜俯视 3D 小人，普攻、3 个基础技能、基本走位、防守/冲锋体验；伤害反馈清晰。
2. **战争有代价**：招募、装备、粮食、行军、伤亡、俘虏、战利品与生产全部前后自洽；严禁生成“剧情专用无成本军队”。
3. **人按自己的判断行事**：重要角色有目标、利益、关系、性格、对胜负的主观评估和不完整情报。退兵、投降、倒戈是可解释的行动选择。
4. **有限一生与有限认知**：世界事实不等于玩家所知；角色有年龄与病伤；死亡终局只揭示可合理知晓之事；允许回到旧存档改变后续。

## 核心游戏循环

军令/利益/求援 → 收集不完整情报 → 选择战争目标 → 招兵与分配真实装备/粮草 → 行军、侦察及远程命令 → 可能接敌的即时战斗 → 结算伤亡、战利品与俘虏 → 局势变化、角色成长/衰老、剧情后果 → 下一轮。

### 战斗界面/操控目标

- 一个可直接操纵的主角，斜俯视摄像机；普通士兵小但可分辨所属队伍、装备轮廓与姿态。
- 近距离快捷命令：跟随、攻击指定敌方、坚守/撤退（早期允许先实现其中三项）。
- 建议从枪兵主角开始：普通刺击；直线突刺、弧形扫击、站稳防御/破阵准备。**非玄幻**，消耗体力或有冷却；不添加独立复杂魔法系统。
- 高级军令通过下属将领和传令执行，允许延误、拒命与错误判断；近身队伍保持响应迅速，避免操作迟滞。
- 溃败比彻底歼灭更常见；士兵可死、伤、逃、被俘。人物死亡必须回写世界。

### 世界对象与不可违反的约束

- City: owner, population, food, arms, armor, horses, production capacity, garrison, fortification, location.
- Army: location, soldiers/contingents, leader, equipment allocations, food, condition, morale, orders.
- Character: age, health, injuries, motives, relationships, perceived facts, command, loyalty **不是**单一投降概率。
- Faction: territory, leadership, aims, military units, relationships.
- IntelReport: subject, observed_at, reported_at, source, confidence, contents; optional misinformation.
- Event: trigger conditions, affected objects, time, consequences; **不得覆盖**已经发生的真实战果以强制剧情。
- 至少在战略层有统一的权威数据源；战斗前将兵力配置物化为近景单位，结束后提交可审计的伤亡/缴获差量。
- 战略军队总量与同屏精细模拟人数独立。大规模军团按编队和区域简化，实际规模由基准测试决定。

### 时间与成长

- 实时战斗秒级；行军小时级；粮食/疲劳/疾病日级；生产月/季级；年龄从世界时间推算。
- 主角初期可设 24 岁。打仗/休养/治理时间推进，体力、健康、旧伤与死亡风险相互影响；自然死亡不是固定 75 岁瞬间触发。
- 技能/属性升级、装备更换来自训练与战利品；主角强大但阵型、箭矢、疾病和时间仍有威胁。
- 主角死则世界在这一局的叙述结束。结局只陈列有证据或能够知晓的消息；不可得的后续以悬念处理。允许读取过去节点，不采用“随机数刷新失败结果”的设计。

## 美术与演出基准

- 模型：真实人体比例的小尺寸 3D 人物，轻量网格、可辨识的衣着剪影、简化却可信的盔甲、磨损及战利品装备差异；重要面部细节由剧情立绘负责。
- 贫民粗布、补丁；富户质料与细节略好但不会像现代奢侈服装；士兵可无甲、穿旧甲或杂甲，重要的是**时代生产条件与个体装备不齐**。
- 镜头远近决定细节密度；大群士兵对单位着色、装备、队形与动作可读性优先于高精模型。
- 色彩低饱和、风尘感、适度古代材料质感；克制的打击反馈，允许悲剧但不靠过度血腥制造情绪。
- 普通叙事：立绘 + 对话 + 背景；关键片段：有限动画、音效与镜头运动，**不要求大量过场影片**。

## 第一段有完整意义的故事：安平救援

**仅作架空设定，可在不破坏机制的情况下更改具体名字。** 王朝暂称“晟”；北境有安平（被围）、平陵（玩家驻地）和河曲（交通/粮道要冲）。敌我两势力；更大政治冲突在背景中，但第一阶段不模拟全国。

人物原型（名字可由 Dot 统一美术与文本）：
- 主角：边军小校，起始 24 岁，少量士兵与有限装备；不是天选之子。
- 安平守将：使命感强，但重视城中居民与部下生存，可能守、撤或议降。
- 平陵军需官：维持粮草，重视可持续防务，对主角提出苛刻约束。
- 一位老兵：拥有可记住的个人经历，可能成长、受伤或战死。
- 敌方将领：既有战略目的，也受补给、军令与手中情报约束；不会因为玩家需要胜利就降低智力。

**初始冲突**：三日前有安平求援；现状可能已变，玩家持有的六十名士兵装备和粮食不足。安平城在离屏状态持续被围、消耗粮食。玩家可以直援、先侦察、走山道、截粮、守本地，也可以派信使谈判或求援（只有实现了相应系统才作为可选行动）。

**允许出现的动态结果**：
- 及时支援，守军获救，但兵力和粮食付出代价；
- 迟到时城已经失陷；抵达后可以撤退、反攻或者谈判；
- 敌粮被截而围城松动，却使本地另一处防线空虚；
- 守将为保存居民而降，未必是个人恶意；
- 玩家死亡，记录已知局势与未尽之事，故事结束。

**禁止**为了固定悲剧把救援强行判失败；也禁止因为玩家路过就给守城方凭空增加粮食和士兵。

## 故事的正式版成长路径

- 边军初任：小队、生活艰难、有限视野；主角认识具体的战友。
- 危机与军功：围城、行军、补给、政治军令；从几人到较大队伍。
- 乱世征战：阵营关系、将领取舍、攻防形势、局部战役发展为军团战争。
- 暮年/终局：年老体衰、离世/战死、理想与现实的落差；成功可有但代价和结果符合历史进程。
这些是主题，不是保证每一局必须经历的关卡。如果早死或拒绝升迁，人生也应有完整而合理的终局。

## 设计原则性测试

1. 物资一致性：不可能从 30 件武器分配出 50 件实际武器；战死/缴获后数字能够核对。
2. 因果测试：同样的世界种子/行动产生一致的战略结果；早走 2 天、调整运粮能够改变城池结局。
3. 情报测试：城池一日前陷落，三日前的报告不会自动更新；斥候到达后可以更新。
4. NPC 测试：面对不确定战况，同一个角色会因关系、个人利益、兵力和情报变化选择不同合理行为。
5. 死亡测试：主角死即结束；结局不泄露世界未知的秘密；读档恢复真实世界与待送达消息。
6. 战斗测试：主角与士兵的伤害、技能、军令、死亡有可感反馈；无无限刷新士兵。
7. 玩家体验：失败能复盘归因，机制有提示，不因不可见作弊造成惩罚。
